# Видео для канала @admiral8dota

Вертикальные ролики про Dota 2 для TikTok и YouTube Shorts — любого формата: графика и интерфейс, 3D-герои, кадры из самой игры, мемы.
Вышли: 002 «Сколько Танго весит Пудж», 004 «С чем пустят в самолёт», 005 «Кунка за 7 лет».

Ролики собираются кодом: озвучка, субтитры, графика и анимация. Рендер идёт в GitHub Actions, готовые ролики — в ветке [`renders`](../../tree/renders) (ссылки на скачивание в её README). Правила работы — [CLAUDE.md](CLAUDE.md); сценки с говорящими героями — [docs/ANIMATION.md](docs/ANIMATION.md); 3D в движке доты — [docs/DOTA_ENGINE.md](docs/DOTA_ENGINE.md).

## Ролик

- 1080×1920, 30 fps. Первый кадр — собранная картинка, начало — сразу по делу.
- Озвучка — Fish Audio (`s2.1-pro-free`, скорость 1.15), голос свой в каждом выпуске (`voice_id`). Эмоции — тегами `[excited] [curious] [sarcastic] [surprised] [confident] [break]`; если голос срывается — ниже `fish_temp` (0.7). Голоса, копирующие реальных людей и известных персонажей, не используются.
- Каждый элемент появляется, когда диктор говорит о нём (`cues`), а не по таймеру.
- Безопасная зона TikTok: x 60–940, y 150–1560. Субтитры по центру (y ≈ 1468), до 3 слов, активное слово на жёлтой плашке.
- Картинки только настоящие: герои, предметы, способности — из файлов игры или Steam CDN; логотипы — с Liquipedia (workflow `assets`).
- Дизайн, звук и начало ролика — [DESIGN.md](DESIGN.md).

## Как собрать ролик на video.py

1. **Сценарий.** `episodes/NNN.json` (схема ниже). Недостающие картинки — workflow `assets` → `assets/…`.
2. **Голос.** `render` вручную с `voices = list` — в ветке `takes` появится `voices.json`; затем `voices = id1,id2,…` — прослушки одной фразой. Выбранный id → `voice_id`.
3. **Дубли озвучки.** `render` вручную с `takes = episodes/NNN.json`. Дубли и `takes.json` с оценкой — в ветке `takes`. Брать выше `prob`, без `weak` на важных словах и без `loud_pauses`. Выбранный mp3 → `voice/NNN/…`, в сценарии `voice_file`, а `voice` — ровно тот текст, которым дубль сгенерирован (по нему строятся субтитры).
4. **Черновик** — `FV_DRAFT=1` (половина размера, 15 кадров/с, быстро) — показать до полного рендера. **Проверка без сети** (~1 мин): `FV_SILENT=1 FV_QA_ONLY=1 FV_QA_DIR=qa python video.py episodes/NNN.json qa/t.mp4` — в конце должно быть «всё в безопасной зоне», кадры смотреть в `qa/`.
5. **Рендер.** Push в `main` → `render` соберёт изменённые выпуски (`out/NNN.mp4`) и выложит в ветку `renders`. Готовый ролик просмотреть покадрово.

Коммиты без рендера — с `[skip ci]`. После правок кода — `python tools/check.py` (все выпуски и сценки разом).

## Сценарий выпуска

```json
{
  "voice_id": "05f3550e4db34a0488e8adda76ae3b9f",
  "hook": { "style": "list", "headline": "Дота|*в жизни*", "voice": "…", "voice_file": "voice/004/hook.mp3",
            "images": ["item:rapier", "hero:earthshaker", "file:assets/ui/daynight.png"],
            "labels": ["Отберут в аэропорту?", "Худший сосед?", "Сколько суток в катке?"],
            "cues": ["предметы", "сосед", "суток"] },
  "parts": [
    { "layout": "mosaic", "headline": "Сколько Танго|весит *Пудж*?",
      "voice": "[curious] Сколько Танго весит Пудж? …", "voice_file": "voice/002/f1.mp3",
      "visual": { "heroes": ["pudge"], "icons": "tango", "count": 9200, "number": "9200 Танго",
                  "caption": "≈ 276 000 золота", "note": "Оценка: …",
                  "cues": { "fill": "огромный", "fill_end": "двести:end", "note": "пятьсот" } } }
  ],
  "outro": { "question": "*Подпишись*", "style": "follow", "voice": "Подпишись и поставь лайк.", "voice_file": "voice/005/end.mp3" },
  "take_texts": [["f2a", "текст варианта", 3]]
}
```

- `hook` — первый кадр: заголовок и наклейки (`hero:`/`item:`/`file:`) с подписями `labels`, каждая на своей метке из `cues`.
- `parts` — части ролика (в старых сценариях ключ назывался `facts`). Любую часть можно описать раскладкой (таблица ниже) или сценой — [SCENES.md](SCENES.md).
- `cues` — слово из озвучки для каждого элемента: `"рошана"` — начало слова, `"минут:end"` — конец, `"квест#2"` — второе вхождение. Времена печатаются при рендере (`метки: …`), «НЕ НАЙДЕНО» — исправить.
- `headline`: `|` — перенос строки, `*слово*` — жёлтым. Ключи героев и предметов — как в dotaconstants (`pudge`, `tango`, `aegis`).
- `outro.style`: `cards` (карточки частей, картинка — `thumb` в `visual`) или `follow` (крупное «Подпишись» и кнопка с ником). `pad` — пауза после фрагмента (по умолчанию 0.7 с).

| layout | для чего | поля `visual` |
|---|---|---|
| `mosaic` | силуэт героя выкладывается иконками, счётчик, лупа | `heroes[1]`, `icons`, `count`, `number`, `caption`, `note` |
| `timer` | матчи и рекорды по времени | `timer` (сек), `teams[2]`, `team_logos[2]`, `winner`, `icons`, `count`, `label`, `event_logo` |
| `gauge` | проценты, винрейты | `heroes[1]`, `number`, `label`, `chips[]`, `ability_icons[]` |
| `duo` | два героя, связь между ними | `heroes[2]`, `caption`, `arc` |
| `block` | один герой и большое число | `heroes[1]`, `number`, `label` |
| `trap` | разоблачение: скрытые данные, сканер, штамп | `logo`, `number`, `label`; метки `panel`, `read`, `number`, `stamp` |
| `range` | дальность: герой на шкале, предел, куда долетел | `heroes[1]`, `icon`, `max`, `land`, `player{name, caption, logos[]}` |
| `notes` | патч: номер версии, строки-эмодзи, расшифровка | `version`, `emoji[]`, `emoji_note`, `icon`, `decoded` |
| `grid` | число и сетка иконок | `number`, `icons`, `count`, `heroes[1]`, `label` |

Новую раскладку добавлять в `video.html` (построение в `init`, анимация в `drawExtra`) и проверять локально.

## Файлы

- `video.py` — озвучка, выравнивание субтитров, картинки, рендер кадров, звук, дубли.
- `video.html` — шаблон: стили, раскладки, анимации, проверка раскладки `audit()`.
- `scene.js`, `scene.css` — сцены из JSON ([SCENES.md](SCENES.md)); `dota_map.js` — материалы карты для 3D в браузере.
- `episodes/` — сценарии выпусков, `voice/` — выбранные дубли, `covers/` — обложки (HTML → PNG: `python tools/cover.py covers/cover_NNN.html`; картинки — только из `assets/`), `assets/` — иконки и логотипы, `fonts/`, `vendor/` — шрифты и библиотеки с лицензиями.
- `tools/` — извлечение файлов игры (`vpk_tool.py`, `dota_export.py`, `map_crop.mjs`), текстуры; `paths.py` — пути к игре, S2V и Blender (переменные `DOTA_ROOT`, `S2V`, `BLENDER`).
- `tools/skit/` — сценка одной командой: сценарий (`skits/*.txt`) → голоса → постановка → Blender → сведение.
- `tools/blender/` — рендер сцены в Blender: герои, мимика, разговор, карта.
- `tools/dota_engine/` — 3D в движке доты: мод-режиссёр, площадка с проверками кадра, автокамера, свои анимации, запись.
- `skits/` — сценарии сценок; `docs/` — инструкции по сценкам и движку доты.
- `.github/workflows/render.yml` — рендер и дубли озвучки (секрет `FISH_API_KEY`); `assets.yml` — герои, предметы, логотипы в ветку `assets`.

## Что сохранено и почему

Модели, карты, текстуры, голоса, платный кэш озвучки, примеры, исходные blend,
результаты и отчёты исследований нужны для воспроизведения. Их размер сам
по себе не доказывает ненужность. Ветки `assets`, `takes`, `renders` и
`*-artifacts` имеют отдельное назначение. Локальные refs `worker/*` сохраняют
пакеты с другого узла и не являются активными локальными рабочими ветками.

Изменения и рабочая папка действующей постановки исключены из удаления.
Очистка `_fv_work` остановлена защитой: обнаружен активный процесс video/QA.

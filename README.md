# Admiral8 Renders

Проект для создания роликов по Dota 2 с локальным рендером.

## Работа через Codex

Откройте репозиторий в Codex и вставьте [промпт для нового чата](docs/SETUP.md#промпт-для-нового-чата-codex). После настройки опишите нужный ролик и приложите референсы.

## Приложение для Windows

Разработка на паузе. Для запуска текущей версии распакуйте [ZIP](https://github.com/yotsug8/admiral8-renders/archive/refs/heads/main.zip) и откройте `Admiral8.cmd`. Поддерживаемые запросы и требования перечислены в [инструкции по настройке](docs/SETUP.md).

# Admiral8 Renders

Создание и редактирование видео через ИИ-агента, Blender и локальные инструменты. Результат — проверенный MP4 и редактируемые исходники.

**[Единое руководство: правила, ТЗ, установка, рабочий процесс и проверки](PROJECT_GUIDE.md).**

Передайте агенту этот репозиторий и описание видео. Произвольная художественная постановка выполняется агентом; встроенные CLI-планировщики поддерживают ограниченные схемы. Платные API и отдельное приложение не требуются.

Код и проверочные примеры входят в поставку. Игровые ресурсы, пользовательские видеопримеры, модели ИИ и результаты работ хранятся отдельно и не скачиваются без необходимости.

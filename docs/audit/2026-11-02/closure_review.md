## Ограничения среды/метода — не закрывать как ошибки реализации

- F08: `scene.js:302,311` оставляет солнце героев (6,10,6), sun_dir задаёт только multiblend карты. Это ограничение настройки, не неверная передача opts; синхронизация нужна только для обещанного общего солнца. FV_GAME_DIR для карт также пока не применяется (`scene.js:308`), в отличие от img/models.
- F09 CSS/шрифты уже имеют отдельное исправление и отчёт style_loading; сохраняются границы снимка до timeline, динамических URL/классов, CSS image-set/cross-fade/imports и Lottie-шрифтов. Бессрочный cache справочников/CDN не является подтверждением актуальных механик игры; валидную картинку неправильного объекта загрузчики не распознают.
- A07: symlink-пробы пропущены по правам Windows; TOCTOU и атомарность отчёта не гарантированы. F10: не проверены Linux flock/сетевые ФС, потоки одного процесса не поддержаны. Live Actions/credentials/branch protection и аварийное восстановление закрытой Dota не подтверждены. Это не повторно открытые I-09/F10/cvars.
- DOM-QA проверяет выбранные кадры и прямоугольники при opacity >0,95; stage-геометрия, окклюзия, одежда, звук и художественное качество не покрыты. Stage-диагностика максимум 10 Гц и рамки/корни не заменяют mesh/subframe-проверку. Метод framing допускает запасной ракурс с помехой и не пересчитывает выбор на всём наезде.
- `anims.py` использует следующий quaternion-key без интерполяции, эвристический stride и ограниченный glTF-reader; это не универсальное воспроизведение glTF. `a8_t` ставит позу корня/sequence, не точную фазу skeleton. Кэши hero_render/anims по пути не доказывают актуальность после смены VPK/S2V.
- `assemble_study --validate-only` подтверждает PNG и путь WAV, не качество WAV; декодирование в stereo не доказывает исходную канальность. `record.sh` листом 24×0,5 с покрывает только первые 12 с; sky_comp при ненайденном cut использует fallback/повтор первого кадра. Это ограниченные свидетельства, не приёмка всего ролика.
- `chase_audio/chase_camera_audio` требуют обычного Python без `-O` (assert исчезают с оптимизацией), конкретных контактов и voice-null окна без посторонних cue. Панорама относится к root в момент события; 10-мс возврат к baseline проверяется по PCM, не слухом. Новый общий аудиодефект отсюда не следует.
- IK/bake/NLA и выбор поверхностей имеют разные контракты; airborne blend=3 против строгого contact bake — кандидат отдельной регрессии, не доказанная поломка прыжка. prepare_forest не обещает идемпотентного повторного вызова, другие forest helpers очищают собственные объекты. Текстовый exec/AST-сборка требуют учитывать вызывающую среду, а не удалять «неопределённые» имена по Pyflakes.
- Подозрение на отсутствие skin-fix в weight_shift уже снято исходным аудитом. apply_panic, hq_textures, prop_attachment, альтернативные framing-функции, процедурные материалы, старые CSS и поддерживаемые flash/beat нельзя объявлять мёртвыми по отсутствию одного вызова; запрет эффекта в дизайне не делает код недостижимым.
- **chase_ground:** исходный отчёт описывает реальный вызов из kunkka_chase и ограничения playback/unit scale/root transform/topology/отката. Файл активно меняется; ни старые выводы о его текущем содержимом, ни исправление не подтверждаются этой сверкой. Требуется результат владельца активной правки, не параллельный ремонт. То же относится к doomsday.
- Старые медиа, 2306 деревьев и игровые ресурсы не просмотрены заново. Полное чтение таблицы, декодирование изображений, upstream-сверка vendor и успешные тесты не доказывают визуальную/слуховую приёмку. `_game` повторно не обходился.

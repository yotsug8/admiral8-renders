# Admiral8 Renders

Репозиторий для создания видео через ИИ-агента и Blender. Пользователь даёт агенту ссылку на репозиторий, описывает ролик и прикладывает референсы. Агент готовит сцену, анимацию, звук, проверяет черновик и выдаёт MP4 вместе с редактируемыми исходниками.

## Начать работу

Передайте агенту:

> Репозиторий: https://github.com/yotsug8/admiral8-renders
> Создай видео: [сюжет, герои, формат и пожелания].
> Открой репозиторий как рабочую папку. Прочитай AGENTS.md, docs/SETUP.md, docs/MASTER_SPECIFICATION.md и актуальную часть docs/PROJECT_STATE.md. Сам выбери и используй технические инструменты. Сначала проверь постановку и движение, затем собери и покажи полный черновик. Сохрани исходники, замечания и точное состояние работы в репозитории.

Агенту нужны доступ к файлам, выполнение команд, Blender, FFmpeg и возможность визуально проверять результат. Для игровых ресурсов Dota нужна установленная игра либо предоставленная пользователем упакованная сцена. Ссылка на GitHub содержит инструкции и инструменты; локальные сцены, игровые файлы и модели нейросетей передаются отдельно.

## Что находится в репозитории

- `AGENTS.md` — правила для агента и критерии проверки.
- `tools/blender/` — подготовка сцен, анимация, контакты, рендер и сборка планов.
- `tools/dota_engine/`, `tools/skit/` — игровые ресурсы, персонажи и звук.
- `video.py`, `SCENES.md`, `episodes/` — вспомогательный конвейер 2D и графики.
- `docs/` — ТЗ, настройка, текущее состояние и замечания по сценам.

Отдельное приложение, GUI, установщик и запуск двойным щелчком исключены из проекта. Командные инструменты предназначены для агента; постановка не ограничивается готовыми шаблонами или встроенным планировщиком.

## Карта проекта и проверки

| Область | Назначение |
| --- | --- |
| `video.py`, `video.html`, `scene*.js`, `scene.css`, `subtitles.css`, `dota_map.js` | 2D, титры, встроенные 3D-модели, проверка и кодирование кадров |
| `tools/quickstart.py`, `scene_revision.py`, `scene_request_3d.py`, `local_scene_planner.py`, `dialogue_request.py` | CLI подготовки и ограниченных правок; ручная постановка ими не ограничивается |
| `tools/blender/` | Рендер, сборка планов, контакты, камеры, риги и постановочные инструменты; `kunkka_polish.py` относится к конкретному ролику |
| `tools/dota_engine/`, `tools/skit/`, `tools/memes.py` | Локальные игровые ресурсы, сцены, речь, звук и каталог клипов |
| `tools/paths.py`, `resource_paths.py`, `render_storage.py` | Поиск программ, общие ресурсы, блокировки и кэш |
| `tools/check*.py`, `tools/test_*.py` | Быстрые, регрессионные и интеграционные проверки |
| `episodes/`, `scenes/`, `skits/` | Воспроизводимые примеры и входы проверок, не остатки приложения |
| `assets/`, `fonts/`, `vendor/` | Используемые ресурсы 2D-конвейера и зависимости с сохранёнными сведениями о происхождении |
| `docs/` | ТЗ, настройка, актуальное состояние, выводы по ролику и отчёт аудита |

После изменения кода: `py -3.11 tools/check.py`. Все модульные проверки:
`py -3.11 -m unittest discover -s tools -t . -p "test_*.py"`.
Полная проверка 2D/3D и восстановления: `py -3.11 tools/check_pipeline.py --out qa/pipeline-new` (новая папка, один GPU-рендер за раз).

Правила находятся в AGENTS и ТЗ; текущее состояние не дублирует историю старых задач. [Результат аудита и ограничения очистки](docs/REPOSITORY_AUDIT.md).

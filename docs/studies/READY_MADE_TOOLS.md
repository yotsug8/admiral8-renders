# Готовые инструменты: отбор под текущие задачи

Проверка источников 01.11.2026. Проекты независимых авторов допустимы
наравне с корпоративными. Источник должен позволять установить конкретную
версию, лицензию, зависимости и способ исполнения. Открытый код и число
звёзд не доказывают безопасность или пригодность для текущего rig.

| Задача | Кандидат и источник | Решение для проекта |
|---|---|---|
| Перенос готового движения на другой скелет | [Retarget, KBSBAUDRICE](https://github.com/KBSBAUDRICE/Retarget), независимый автор | Первый кандидат: статический аудит и двухсекундная проба описаны в [RETARGET_CANDIDATES](RETARGET_CANDIDATES.md). API/bake/reopen проверены на 5.2; [Пудж](RETARGET_CHARACTER.md) — только малое движение, [разные длины](RETARGET_PROPORTIONS.md) и [оси](RETARGET_AXES.md) — без кожи. UI/произвольный mocap не подтверждены |
| Альтернативный retarget | [Mwni Animation Retargeting](https://github.com/Mwni/blender-animation-retargeting/blob/stable/blender_manifest.toml) | Manifest 2.4.0, GPL-3.0-or-later, минимум Blender4.4. Нижний предел не доказывает 5.2; второй addon сейчас не устанавливать, вернуться при конкретном провале первого |
| Библиотека готовых человеческих движений | [Mixamo FAQ](https://helpx.adobe.com/creative-cloud/faq/mixamo-faq.html) | Бесплатно с Adobe ID, библиотека для двуногих гуманоидов. Не решение четвероногого бега Худвинк; необычные пропорции/хвост/одежда ограничивают autorig. Вход и загрузка моделей не выполнялись |
| Захват движения камерой | [FreeMoCap](https://github.com/freemocap/freemocap) | Открытый проект, AGPL; есть CPU-режим. Текущий README содержит отдельные варианты установки и закрытые git-зависимости для source setup. Перед выбором нужен аудит закреплённого release/зависимостей и пригодных входных записей. Не разворачивать стек ради эксперимента без исходного движения |
| Свет, материалы и наполнение окружения | [Poly Haven](https://polyhaven.com/license) | HDRI, текстуры и модели CC0. Брать конкретный необходимый asset и проверять импорт/масштаб/стиль в кадре; API и addon имеют отдельные условия. Пустой горизонт исправляется постановкой окружения, а не одной цветокоррекцией |

Для глаз нынешний дефект локализован в геометрии и морфах головы
([EYE_CALIBRATION](EYE_CALIBRATION.md)). Дополнительный коннектор управления
Blender не исправит эти данные. Новый face rig требует отдельной проверки
век, зрачков, речи и сохранённых эмоций на копии; автоматический ремонт
готовым пакетом не обещан. Платные face/physics-пакеты не закупались.

Порядок: одна проблема → один кандидат → статический просмотр закреплённого
пакета → изолированная короткая проба → сравнение с существующим методом.
Включать в производство только при измеримой пользе и визуальном улучшении.
Фиксировать версии/хеши и инструкцию воспроизведения в репозитории;
сторонние ассеты и установленные зависимости учитывать отдельно.
Никакие addons по этой карточке ещё не установлены.

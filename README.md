# Admiral8 Renders

Проект для создания видео через ИИ-агента и Blender: от запроса и референса до проверенного MP4 и редактируемой сцены.

**Все инструкции в одном месте: [PROJECT_GUIDE.md](PROJECT_GUIDE.md).** Внутри — правила, полное ТЗ, подготовка окружения, проверки, состояние, уроки прошлых роликов и карта инструментов.

Код, ресурсы и необходимые исходники сохранены. Отдельное приложение не используется.

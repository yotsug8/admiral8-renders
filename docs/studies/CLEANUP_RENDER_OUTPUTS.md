# Очистка промежуточных рендеров — 02.11.2026

Удалены 6762 файла из старых локальных проб и версий погони:
последовательности кадров, устаревшие черновые MP4 и три промежуточные
карты `probe14/map_debug.blend`, `map_culled.blend`, `map_updated.blend`.
Сумма размеров файлов — 5 410 378 613 байт; после очистки и возврата
актуальных результатов на системном диске свободно около 4,4 ГиБ.
Опись с относительными путями — `_game/study/cleanup-c-2026-11-02.json`.

Сохранены финальные карты, используемые camera/actor-кэши, исходники,
ресурсы персонажей и окружения, голоса, коллекция примеров, текущие
постановки и результаты в renders. Эти кэши имеют действующие ссылки;
их удаление требует изменения сборки, а не только освобождения места.

Актуальные Rain-видео, отчёты и выбранные ключевые кадры возвращены
в `_game/study/rain_effort/delivery` и `_game/study/rain_rise/delivery`.
Копии сверены по SHA256. Временные полные последовательности и ранние
дубли этих упражнений на дополнительном диске удалены. Новые выходы
снова по умолчанию пишутся внутри проекта на системном диске.

Исторические упоминания полных последовательностей в отчётах описывают
проведённую проверку, а не обещают хранение каждого промежуточного PNG.
Для повторного сведения удалённых последовательностей требуется рендер
из сохранённой сцены/сценария. Чужие примеры и актуальные результаты
обучения не считать мусором вместе с временными кадрами.

## Подтверждённые изменения

A07 оставался актуален: четыре указанных CLI напрямую вызывали `write_text`
с пользовательским выходным путём. Camera, contact и continuity делали это
также после ошибок анализа. Проверка mtime в gait выполнялась **до** записи
и не предотвращала перезапись исходной сцены.

У deformation уже были проверка `resolve()`, совпадения с двумя входами,
расширения `.blend` и существующего родителя. Они не обнаруживали hardlink
на исходник с другим именем и расширением `.json`.

Добавлен общий helper из двух функций, без новых зависимостей:

- `json_output_path` разрешает путь, запрещает `.blend` без учёта регистра
  у заданного имени и разрешённой цели, требует существующего родителя,
  проверяет равенство разрешённых путей и `samefile` существующих файлов.
- `write_json_report` выполняет эту проверку непосредственно перед записью.
  Все пять CLI используют его вместо прямого `write_text`.

Защищены загруженная сцена у camera/contact/continuity, исходная сцена у gait,
оба явных входа у deformation. Тем же механизмом защищены metadata у gait
и storyboard у continuity. Пустой `bpy.data.filepath` не превращается в путь
рабочего каталога. Deformation сохраняет предварительную проверку перед
загрузкой сцен и дополнительно проверяет путь перед записью.

CLI-флаги, обязательность `--json`, формат/кодировка JSON и расчёт метрик
сохранены. Camera и continuity возвращают 2 при отказе записи; contact
использует прежний выход с кодом 2. Gait по-прежнему передаёт исключения
Blender, поэтому для надёжного ненулевого process exit нужен
`--python-exit-code 2`; отдельный обработчик ему не добавлялся.

## Выполненные проверки

Новый тест содержит 15 методов, часть с несколькими сценариями для пяти CLI.
Окончательный запуск: **13 прошли, 2 пропущены** в Blender 5.2.3 LTS.
Ни рендер, ни игровые ресурсы не использовались.

- Для каждого из пяти настоящих `main()` на синтетической сцене проверены
  равный путь, относительный нормализуемый путь `child/../scene.blend`
  и существующий hardlink `.json`. Проверяется отказ и точное равенство
  `read_bytes()` каждого входа байтам до вызова, а не только статус/mtime.
- Отдельно проверен hardlink на второй вход deformation.
- Metadata и storyboard сохраняют байты при попытке записать в них отчёт.
- Ошибка анализа camera/contact/continuity не позволяет записать ошибочный
  отчёт поверх сцены; deformation отклоняет такой выход предварительно.
- Все пять утилит создают обычный JSON по отдельному допустимому пути.
- Helper отдельно проверен на входе без расширения `.blend`, алиасе регистра
  на файловой системе Windows, существующем hardlink, отсутствующем родителе,
  запрете `.blend`/`.BLEND`, пустом пути несохранённой сцены и повторной записи
  в отдельный отчёт.
- Два реальных symlink-теста пропущены: Windows вернула WinError 1314
  (нет привилегии создания символьной ссылки). Успешная проверка symlink
  не заявляется; тесты сохранены для окружения с нужными правами.

В том же лёгком Blender-запуске прошли **5 существующих тестов deformation**.
Отдельно прошли **5 CPU-тестов shot_continuity**. Итого окончательных
проверок: **23 прошли, 2 пропущены**, без повторного подсчёта ранних запусков.
Синтаксис всех семи новых/изменённых Python-файлов проверен через `compile`;
`git diff --check` не обнаружил ошибок whitespace.

Команды воспроизведения (BLENDER — путь к установленной программе):

```powershell
& $env:BLENDER -b --factory-startup --disable-autoexec --python-exit-code 2 -P tools/blender/test_blender_output_safety.py -P tools/blender/test_deformation_metrics.py
py -3.11 tools/blender/test_shot_continuity.py
```

Локальный `py -3.11` сообщил об отсутствии установленного Python 3.11.
CPU-тесты выполнены доступным Python 3.10.11; Blender использовал свой Python.
Первый sandbox-запуск Blender завершился без вывода; разрешённый запуск вне
sandbox выполнил проверки. Hardlink в sandbox также был недоступен, но вне
sandbox проверен успешно. При первом интеграционном запуске тестовый перехват
`os._exit` терял аргумент кода; исправлен сам перехват, затем весь набор
успешно повторён. Сохранность байтов не нарушалась и в том запуске.

## Ограничения и передача

Защита рассчитана на стабильные пути: она не устраняет TOCTOU, если другой
процесс подменит файл/ссылку между проверкой и открытием. Запись обычного
отчёта не стала атомарной. Не защищаются все внешние ресурсы сцены, а только
перечисленные входы; повреждение отдельного отчёта при сбое записи не исключено.
Обнаружение symlink предусмотрено через `resolve`, но фактическая проба
на этом компьютере пропущена по указанной причине.

Интеграционные тесты вызывают настоящие парсеры и `main()` в Blender;
`os._exit` contact перехватывается для продолжения набора. Отдельные процессы
для каждого CLI и их внешние оболочки этой проверкой не охвачены.

Изменены только пять согласованных исходников; добавлены узкий helper,
один тестовый файл и этот отчёт. Общий check.py и GPU-рендер не запускались.
Другие рабочие изменения, включая video.py, check.py, chase_ground и
doomsday*, не редактировались. Коммит и push не выполнялись.

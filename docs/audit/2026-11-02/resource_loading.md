# F09 — браузерная загрузка изображений

Дата: 2026-11-02. Область исправления: `video.html`, `dota_map.js`.
Регрессии: `tools/test_resource_loading.py`. Только браузерная часть;
Python `image_ref`, кэш кадров/WAV и F11 этим отчётом не подтверждаются.

## Прослеженный поток и воспроизведение до исправления

- `init()` строит DOM через раскладки либо `SCN.build()`. Обычные картинки
  и скрытые кадры anim/video входят в `document.images`. Прежнее ожидание
  считало `onerror` успехом, а `complete` принимало без проверки размеров.
- Картинки hero/icon мозаики создаются вне DOM. `buildMosaic()` ожидал
  только `onload`, последовательно, либо пропускал ожидание по `complete`.
- `prepareDotaMap()` запускает TextureLoader для multiblend-слоёв и
  tint-маски. Прежний error callback разрешал Promise; `ready` давал
  ложный успех. Вызывающая цепочка прочитана: `init → SCN.load → stage →
  await map.ready`. Полный stage с GLB в тестах не запускался.

На исходном коде три тестовых метода дали **7 ожидаемых провалов**:
DOM с HTTP 404/повреждёнными байтами и карта с отсутствующим цветовым
слоем/повреждённой маской возвращали успех (4 случая); мозаика с ошибкой
hero/icon, включая зависший hero перед битым icon, не завершалась
до тестового watchdog (3 случая).

## Минимальные изменения

- Общий `waitForImage()` для DOM и мозаики отклоняет Promise при error,
  нулевых naturalWidth/naturalHeight, включая уже завершившуюся неудачную
  загрузку. Сообщение содержит источник; при отсутствии адреса —
  `[пустой src]`. Собственные слушатели и таймер удаляются при завершении.
- Оба изображения мозаики ожидаются одновременно: ошибка icon больше
  не скрывается за незавершённой загрузкой hero. В диагностике есть
  `Мозаика hero`/`Мозаика icon`; проверка предшествует drawImage.
- Ошибка TextureLoader теперь отклоняет `map.ready` с URL и префиксом
  `Текстура карты`. Повторные ссылки на текстуру сохраняют прежний кэш.
- Каждое ожидание ограничено **30000 мс**. Для сетевой ошибки отказ
  немедленный по событию, для неотвечающего запроса — именованный таймаут.
  Это предел отдельного ожидания, а не общий срок всего `init()`.
  Незавершённые соседние запросы не отменяются; успех подготовки после
  ошибки не выдаётся, закрытие браузера остаётся задачей вызывающей стороны.

## Проверка после исправления

```powershell
python -m unittest tools.test_resource_loading -v
```

Использован явно выбранный Python 3.11 и реальный Chromium вне sandbox.
**13 тестов прошли, exit 0**, длительность тестового прогона около 4,8 с.
Библиотеки Three.js/GSAP/scene.js загружаются из репозитория, PNG создаётся
в памяти. HTTP-сервер слушает только loopback, использует свободный порт
и не меняет файлы проекта. Внешние запросы блокируются и считаются ошибкой
теста. Python-конвейер, TTS, ASR, игровые ресурсы и платные сервисы не вызываются.

| Проверка | Подтверждённое поведение |
|---|---|
| DOM: отложенные 404 и повреждённый PNG | `init()` отклонён с адресом ресурса |
| DOM: битый img уже complete, img без src | Отказ вместо пропуска проверки |
| DOM: img/hero/card и скрытые anim/video | 5 изображений имеют размеры 8×8; оба canvas после seek содержат ожидаемый RGBA |
| Скрытые кадры anim/video с битым вторым кадром | `init()` отклонён до рисования |
| Мозаика: ошибки hero/icon во время ожидания | Отказ с адресом; битый icon не ждёт зависший hero |
| Мозаика: уже complete битый hero или icon | Именованная ошибка до drawImage |
| Исправная мозаика | 250 точек, конечные координаты лупы, непрозрачный пиксель canvas после seek |
| Карта: отсутствующий color3, повреждённая tint-маска | Настоящий TextureLoader отклоняет `ready` с адресом |
| Исправная карта | Все 5 texture uniform имеют загруженные изображения 8×8; общий ресурс запрошен один раз |
| Зависший запрос DOM, мозаики и карты | Все три ожидания отклонены с URL и таймаутом 30000 мс |

Таймауты проверяются переводом часов Playwright на 30001 мс при настоящем
незавершённом локальном HTTP-запросе; это не 30 секунд настенного ожидания.
Image, события загрузки, декодирование и TextureLoader не подменяются.
Отдельный двухсекундный watchdog защищает отрицательные регрессии от
бесконечного `page.evaluate`. Необработанных browser exceptions нет.
`git diff --check` для двух изменённых production-файлов прошёл.

## Непроверенные области

- **GLB и Lottie**: загрузка, внутренние/внешние ресурсы и зависания не
  покрыты; полный stage и GPU-отрисовка шейдера карты не проверены.
- **Внешние CSS-фоны**, прочие CSS-текстуры, шрифты и ресурсы, добавляемые
  после снимка `document.images`, не входят в ожидание изображений.
- Текстуры bed/bank, загружаемые напрямую в `scene.js`, а также текстуры
  обычных GLB-материалов не проходят через новый error callback карты.
  Проверены только вызовы TextureLoader внутри `prepareDotaMap()`.
- Не проверяются полнота списков кадров, семантическая правильность
  картинки, качество готового ролика или Python-кэш. Валидная заглушка
  остаётся валидным изображением с точки зрения браузера.

Общий `check.py`, рендер выпуска, коммит и push не запускались. Общие
документы, `video.py`, `scene.js` и производственные Blender-файлы не
изменялись в рамках этой работы. F09 целиком закрытым не объявляется.

# Память проекта и продолжение работы

Обновлено 30.10.2026 при переносе из Claude Code в Codex. Читать после AGENTS.md в новом чате. Это перенос значимых решений из памяти Claude и истории работы; исходные файлы памяти на этом ПК сохранены в `.claude`, но для продолжения они не нужны.

## Цель и рабочий цикл

- Сейчас важен навык делать анимационные сценки уровня образцов, а не выпуск очередного ролика. Пробы — короткие, по одному навыку; полный рендер после одобрения или прямой просьбы.
- Образцы — `_game/study/examples/` (14 видео). Сравнивать с общим уровнем всех, не копировать один ролик. Подробные правила — docs/ANIMATION.md.
- Жесты и позы делать своими ключами костей. Игровые анимации использовать, когда они уместны; стойка служит основой дыхания и покачивания.
- Намеренно странное движение может быть смешным: Т-поза, скольжение, нелепая поза. Сильное искажение лица — на кульминации. Жесты по словам включать только меткой там, где нужны.
- Не объявлять визуальный дефект исправленным по маленькому листу проб: смотреть крупно, с разных сторон, по всей длине; движение проверять покадровыми замерами. Проверка кода не заменяет просмотр рендера.
- Для движения есть быстрые пробы без карты (`A8_FAST=1`, views_world.py); для оценки итоговой картинки нужна настоящая карта. Изменение света проверять на нескольких героях и планах.

## Принятый вид

- Герои: мягкий почти ровный свет `DOTA amb=0.95, key=0.35`, исходные текстуры игры. Более объёмный свет и текстуры ×4 с повышенной резкостью отвергнуты: модели выглядели слишком резкими.
- Размытие: селфи f/1.4, крупно по умолчанию f/1.2, средний f/1.6. Варианты вида показывать рядом в полном размере 1080×1920, маленькие изображения для выбора недостаточны. Запасная метка git — `look-v0`; не откатывать к ней весь проект, она предшествует новым возможностям.
- Фон: старое место сцены на `radiant_wide`, солнце сбоку с тенями, рассеянный свет 2.9 (деревья не должны стать тёмными), дымка 0.25. Солнце одно на сцену: перестановка на каждой склейке заставляла тени прыгать.
- Небо — из доты, мягкие кучевые облака (`A8_SKYIMG=1` по умолчанию). Новое место на центральной линии с башней и сухими деревьями не выбрано.
- В анимационных сценках нет субтитров: герои говорят сами. `SUBS=1` — включить по отдельной просьбе. В выпусках `video.py` субтитры остаются.

## Что сделано и что осталось проверить

- Реализованы свой шаг и переваливание, повороты с переступанием, замах оружием, асимметричные гримасы, планы реакции и вид от первого лица; жесты по словам — по метке. Пробы — `skits/probe4–8.txt`, `probe10–13.txt` (нумерация с пропусками).
- Проверки оружия и рывков — `A8_CLIP`, `A8_JERK`, касания собеседника — `A8_WALL` в views_world.py. Последние изменения касаний и нескольких шагов в одной реплике не считать принятыми только по наличию кода: последний коммит этой серии прямо помечен «не проверено рендером».
- Возможен сдвиг позы на переходе своя анимация → игровая стойка; см. docs/ANIMATION.md. Не сообщать, что он устранён, без проверки.
- Звуки крюка уже подключены в mix.py: бросок, попадание, возврат, стоп; время берётся из сцены, звук короче действия и тише речи. Шаги Пуджа выгружены в `_game/sfx/step01–04`, автоматическое подключение шагов ещё не сделано.
- Крюк после возврата снова у Пуджа в руке, цепь в конце исчезает. Вариант с цепью, остающейся в жертве, отменён.
- Клон голоса Снайпера без сдвига на 3 полутона; образец — выбранные реплики с правильным текстом. `pitch` предназначен для голоса Windows. Сам звук агент не слышит; громкость, распознавание и частота голоса не доказывают качество тембра.
- Итоговая проба картинки и звуков без субтитров — `probe4_look.mp4` в ветке `renders`. Ветка также содержит пробы движения, лиц и монтажа. Одобрение одной пробы не означает одобрение всех последующих изменений.

## Файлы, синхронизация и несколько агентов

- Код, правила и сценарии — git; ролики — ветка `renders`, рабочая копия `_game/renders_wt`. Ветки `assets`, `takes`, `renders` используются workflows.
- `_game` исключена из git: модели, карты, мир, данные, озвучка, звуки, небо, примеры и мемы хранятся только локально. Проверка GitHub не заменяет резервную копию этих ресурсов.
- В начале задачи проверить `git status`; при синхронизации — fetch и сравнение локальных веток с origin. Старые облачные ветки назывались `ccr-*`; ветки Codex обычно `codex/*`. Нельзя автоматически сливать всё подряд или перетирать изменения соседнего агента.
- Два агента в одной папке видят один рабочий каталог: заранее делить файлы, читать diff перед staging, при пересечении использовать отдельные worktree. Не коммитить незаконченные правки другого агента.
- Полные рендеры запускать по очереди на RTX 2060 Super. Не менять общие входные файлы и модели во время рендера; новый код не меняет уже запущенный процесс или готовые кадры.
- «Наведи порядок»: опись → список с размерами и причиной → согласованное удаление. Сохранять ресурсы, cache, текущие пробы других агентов, `_check`, `kryuk`, бэкапы настроек доты; защищать worktree `renders_wt`. Публикация — по запросу или в явно разрешённом объёме.
- Когда история разрастается, держать короткую передачу в документах и предлагать новый чат. Новый чат создавать только по просьбе пользователя; не копировать туда всю историю.

## Настройка этого ПК

- Windows, Python 3.11, Node, Blender 5.2.3, Source2Viewer и дота с Workshop Tools проверены. Пути — tools/paths.py. Fish API key — переменная окружения пользователя, ключ не писать в файлы проекта и вывод команд.
- Playwright Chromium установлен 30.10.2026; полный `py -3.11 tools/check.py` прошёл после установки.
- `.codex/config.toml` содержит MCP Blender и Context7. Context7 проверен запросом. Blender MCP требует открытого Blender и запущенного аддона; при миграции аддон не отвечал, фоновый Blender запускается независимо.
- RTK настроен в глобальной `.codex`, через `rtk hook codex`. Исходная настройка Claude сохранена. Поведение старых SendUserFile и ссылок на чаты Claude не переносить буквально: пользоваться средствами Codex.
- Формат инструкций: [AGENTS.md](https://learn.chatgpt.com/docs/agent-configuration/agents-md), [MCP и конфигурация](https://learn.chatgpt.com/docs/config-file/config-reference).

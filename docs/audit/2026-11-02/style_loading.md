# F09: CSS-фоны и шрифты

`document.fonts.ready` разрешается и после ошибки шрифта, а CSS-картинки
не входят в `document.images`. Поэтому подготовка могла успешно закончиться
с запасным шрифтом или без текстуры. Это продолжение [GLB/Lottie](scene_loading.md).

## Исправление

`scene_resources.js` подключается до CSS. Он запоминает ошибки stylesheet:
в Chromium при HTTP 404 `link.sheet` бывает непустым, одного этого поля мало.
Перед раскладкой текста `init` ждёт загрузки всех зарегистрированных FontFace,
проверяет картинки вычисленных background/mask/border/list-style/content
для элементов и их `::before/::after`, включая пока скрытые планы.
Одинаковые URL проверяются один раз. CSS escaping, data URI и пути из внешней
таблицы учитываются; ссылки на SVG-маску внутри документа не загружаются
как отдельная картинка. Ожидание ограничено 30 секундами, ошибки именованы.

## Проверка

```powershell
py -3.11 -B -m unittest tools.test_style_loading tools.test_resource_loading tools.test_scene_loading tools.test_dom_audit tools.test_segment_visibility -q
py -3.11 tools/check.py
```

43 теста прошли, из них 9 новых CSS/FontFace. Общий check: 18 выполнено,
0 пропущено, всё в порядке. Проверки используют реальный Chromium,
декодирование WOFF2/PNG, loopback HTTP и программный WebGL в 3D-пробах.
Зависшие запросы проверяются переводом часов, а не подменой загрузчика.

Новые случаи: отсутствующая/битая картинка фона, маски и border-image;
generated content и псевдофон; фон позднего плана; многослойный фон;
URL относительно CSS и кавычка/скобки в адресе; отсутствующий/битый/медленный
шрифт; отсутствующая таблица стилей; таймаут изображения и шрифта.

## Границы

Снимок делается после построения DOM и до timeline. Ресурсы, созданные
позже произвольным JS, смена классов/URL из пользовательского timeline,
все формы CSS image-set/cross-fade, вложенные stylesheet imports и шрифты,
добавляемые самой Lottie, отдельно не проверены. Проверка не гарантирует
наличие каждого глифа и художественную пригодность выбранного шрифта.
При ошибке штатный процесс закрывает браузер; повторное использование
страницы после ошибки не предусмотрено. Чужие production-файлы не изменялись.

# Контракты сцен и последовательные крюки

Закрытие остатка сверки 02.11.2026: frontend timing/id, F08, I-11,
определение игровых зависимостей и сохранение событий после крюка.

## Изменения

- `video.py` проверяет описание до вызова озвучки, затем разрешённые метки.
  Неизвестное время больше не означает ноль в браузере или пропуск звука.
  Повторные id, включая вложенные и defaults контейнера, отклоняются.
- `scene.js` повторяет защиту времени/id при прямом использовании renderer;
  словарь элементов не наследует специальные свойства Object.prototype.
  Солнце героев и shader карты получают общий проверенный `sun_dir`.
- `tools/check.py` определяет игровые зависимости по разобранному JSON,
  независимо от пробелов и переноса строк. Текст с похожим фрагментом JSON
  сам по себе не означает тип model/stage.
- `skit.py` заменяет анимацию цели лишь на интервале притягивания, сохраняя
  последующие реплики. Последовательные крюки учитывают предыдущую посадку;
  завершившийся первый крюк больше не маскирует второй. Совпавшие исходные
  позиции дают понятный отказ; нулевая длительность возврата не делится на ноль.
- Демонстрационные цифры `demo_layouts.json` помечены как условные;
  комментарии probe7/skit_talk соответствуют команде и эвристическому stride.
- SCENES.md описывает отказы и доверенный характер входного JSON.

## Проверки

```powershell
py -3.11 -B -m unittest tools.test_scene_contract tools.test_media_timing tools.test_qa_coverage tools.skit.test_hook_sequence -q
py -3.11 -B -m unittest tools.test_scene_loading tools.test_scene_contract tools.skit.test_hook_sequence -q
```

Первый набор: 30 успешных тестов. Второй после изменения солнца: 26 успешных
тестов, включая 14 проверок загрузки сцены. Наборы пересекаются, суммировать
их как независимые нельзя. Browser-пробы используют настоящий Chromium
и software WebGL; проверка направления читает реальный DirectionalLight
и аргумент shader, не заменяя загрузчик GLB. Платная озвучка не вызывалась.

Ранее первый запуск набора обнаружил неправильный package-import в
test_qa_coverage; исправлено на `from tools import check`, затем набор прошёл.

## Ограничения

Это не полная JSON Schema и не sandbox чужих сценариев. Произвольный HTML,
локальные пути и скрипты по-прежнему требуют доверенного автора.
Общее направление света не доказывает художественное качество кадра.
Крюки проверены для последовательных событий со статическими позициями;
сочетание с произвольной ходьбой, контактом и независимой сменой траектории
не подтверждено. Автоматические тесты не заменяют просмотр героя с оружием.

# Admiral 8 — ролики «факты о Доте»

Шаблонные вертикальные видео для TikTok-канала **@admiral8dota**: 3 факта о Dota 2 + короткий финал «подпишись».
Рендер идёт в GitHub Actions, готовые ролики — в ветке [`renders`](../../tree/renders) (ссылки на скачивание в её README).

## Формат ролика

- 1080×1920, 30 fps, 35–45 с. Порядок: короткий кликбейтный хук по всему ролику (~2–4 с) → самый абсурдный факт первым → ещё два → финал.
- Факты не обязательно киберспортивные: лучше всего заходят малоизвестные абсурдные вещи (механики, решения Valve, баги). Прикидки «сколько X в Y» не повторять из выпуска в выпуск.
- Факты: **абсурдные, но правдивые и проверяемые**. Каждый — минимум по двум источникам (Liquipedia, Dotabuff, патчноуты, киберспортивные СМИ). Оценки и прикидки — явно как оценки, со сноской «Оценка: …» в кадре. Игровые механики сверять с патчноутами последних патчей (`patchnotes.json` в dotaconstants, Liquipedia): поля в `items.json`/`abilities.json` бывают устаревшими — так в 003 попал штраф Блинка, убранный в 7.39. Банальщину, которую знают все, не брать.
- Озвучка: Fish Audio, модель `s2.1-pro-free`, скорость 1.15. **Голос мемный и свой в каждом выпуске** (`voice_id` в эпизоде; использованные: `0036c4fdc4c7442e9a47af59287b7737` «Мем ии озвучка», `05f3550e4db34a0488e8adda76ae3b9f` «Баба Валентина» — выпуск 002, `9aba4e6d941b4894b073cfc33852bd20` «Мем» (роботизированный) — пробовался в 003, срывался; `2270bb203a424d1881678ba5e4b82b54` «Инциденты 2.0» — выпуск 003). `fish_temp` в выпуске (по умолчанию 0.85) — ниже, например 0.7, если голос срывается. Голоса, копирующие реальных людей (политиков, блогеров, актёров) или известных персонажей фильмов/мультфильмов, не использовать. Живо, с паузами и эмоциями через теги `[excited] [curious] [sarcastic] [surprised] [sad] [confident] [break] [long-break] [emphasis]`. Без `[sighing]` и без `[laughing]` в середине текста. Предложения короткие, без канцелярита.
- Синхрон: каждый элемент на экране появляется, когда диктор произносит слово про него (`cues` в выпуске), а не по таймеру.
- Финал: заголовок «Подпишись», карточки трёх фактов (герой / логотип победителя / иконка), одна строка подкола. Не навязчиво, без вопросов «а какой факт самый дикий?». Без текста фактов на карточках.
- Никнейм — только мелкий водяной знак. Никаких названий рубрик, тегов, «абсурдометров».
- Стиль: тёмная инфографика (графит `#15171c`, жёлтый `#ffd23f`, белый), шрифты Unbounded 900 / Manrope, толстые тёмные обводки и жёсткие тени у плашек и карточек, герои с белым контуром как наклейки, жёлтая шторка между фактами.
- Всё крупно и читаемо; надписи не накладываются друг на друга, на героев и на субтитры. Безопасная зона TikTok: x 60–940, y 150–1560. Субтитры по центру (y ≈ 1468), до 3 слов, активное слово на жёлтой плашке.
- Картинки только настоящие: рендеры героев и иконки предметов/способностей со Steam CDN, логотипы команд и турниров — с Liquipedia (прозрачные PNG, не вырезать вручную).

## Как сделать новый выпуск

1. **Факты.** Подобрать 3 факта, проверить источники.
2. **Эпизод.** Создать `episodes_fv/NNN.json` (схема ниже). Картинки, которых нет в репозитории (логотипы, иконки способностей), скачать workflow `assets` и положить в `assets/…`.
3. **Голос.** Запустить `render` вручную с `voices = list` — в ветке `takes` появится `voices.json` (популярные русские голоса). Выбрать 6–8 мемных кандидатов (не повторяя прошлые выпуски), запустить `voices = id1,id2,…` — прослушки `voice_<id>.mp3` одной фразой. Выбранный id → `voice_id` в эпизоде.
4. **Дубли озвучки.** Запустить `render` вручную с полем `takes = episodes_fv/NNN.json` (у фрагментов ещё нет `voice_file`, либо варианты в `take_texts`). Дубли и `takes.json` с оценкой появятся в ветке `takes`.
   Выбирать по `takes.json`: выше `prob` (разборчивость), нет `weak` на важных словах, нет `loud_pauses` (смех/вздохи/шум в паузах). Выбранный mp3 → `voice/NNN/f1.mp3` и т. д., в эпизоде `voice_file`, а `voice` — ровно тот текст, которым дубль сгенерирован (по нему строятся субтитры).
5. **Проверка вёрстки локально** (без сети и озвучки, ~1 мин):
   `FV_QA_ONLY=1 FV_FAKE_TTS=1 FV_QA_DIR=qa python facts_video.py episodes_fv/NNN.json qa/t.mp4`
   В конце печатается проверка раскладки — должно быть «всё в безопасной зоне». Кадры смотреть глазами в `qa/`.
6. **Рендер.** Push в `main` → workflow `render` соберёт все `episodes_fv/*.json` (~6 мин) и выложит mp4 в ветку `renders`. Скачанный ролик просмотреть покадрово (раз в секунду) перед отправкой.

Коммиты, которые не должны запускать рендер, — с `[skip ci]`.

## Сцены — любой ролик из JSON

Любой сегмент можно описать сценой: элементы, текстуры, рамки, появления и эффекты на GSAP, переходы `push/zoom/flash`, стили субтитров. Справка — [SCENES.md](SCENES.md), пример — `episodes_fv/demo_scene.json`. GSAP лежит в `vendor/gsap` (бесплатная лицензия GSAP, https://gsap.com/standard-license).

## Схема эпизода

```json
{
  "voice_id": "05f3550e4db34a0488e8adda76ae3b9f",
  "hook": { "headline": "Это *правда*|было в Доте", "voice": "…", "voice_file": "voice/003/hook.mp3",
            "images": ["item:gem", "item:blink", "file:assets/abilities/hoodwink_scurry.png"],
            "cues": ["ловушка", "штраф", "патч"] },
  "facts": [
    { "layout": "mosaic", "headline": "Сколько Танго|весит *Пудж*?",
      "voice": "[curious] Сколько Танго весит Пудж? …", "voice_file": "voice/002/f1.mp3",
      "visual": { "heroes": ["pudge"], "icons": "tango", "count": 9200, "number": "9200 Танго",
                  "caption": "≈ 276 000 золота", "note": "Оценка: …",
                  "cues": { "fill": "огромный", "fill_end": "двести:end", "note": "пятьсот" } } }
  ],
  "outro": { "question": "*Подпишись*", "cta": "строка подкола", "voice": "…", "voice_file": "voice/002/end.mp3" },
  "take_texts": [["f2a", "текст варианта", 3]]
}
```

`cues` в `visual` — слово-метка из озвучки для каждого элемента: `"рошана"` — начало слова, `"минут:end"` — конец, `"квест#2"` — второе вхождение. Найденные времена печатаются при рендере (`метки: …`), «НЕ НАЙДЕНО» — исправить. Ключи: mosaic — `fill`, `fill_end`, `note`, `pill`; timer — `clock_done`, `teams`, `icons`, `icons_end`, `label`, `win`, `pill`; gauge — `number`, `label`, `chips`; block — `number`, `label`; grid — `icons`, `label`; duo — `hook`, `pill`.

`hook` — кадр перед фактами: заголовок и три наклейки (`hero:`/`item:`/`file:`), каждая появляется на своей метке из `cues`. Дубли хука и финала делаются вместе с фактами, если у них нет `voice_file`.

`headline`: `|` — перенос строки, `*слово*` — жёлтым. Ключи героев и предметов — как в dotaconstants (`pudge`, `dawnbreaker`, `tango`, `aegis`).

| layout | для чего | поля `visual` |
|---|---|---|
| `mosaic` | «сколько X в Y»: силуэт героя выкладывается иконками, счётчик, лупа | `heroes[1]`, `icons`, `count`, `number`, `caption`, `note` |
| `timer` | матчи и рекорды по времени | `timer` (сек), `teams[2]`, `team_logos[2]`, `winner`, `icons`, `count`, `label`, `event_logo` |
| `gauge` | проценты, винрейты | `heroes[1]`, `number` («39%»), `label`, `chips[]`, `ability_icons[]` |
| `duo` | два героя, связь между ними | `heroes[2]`, `caption`, `arc` (false — без траектории) |
| `block` | один герой и большое число | `heroes[1]`, `number`, `label` |
| `trap` | ловушка/разоблачение: панель скрытых данных, сканер, штамп БАН, логотип и счётчик | `logo`, `number`, `label`; метки `panel`, `read`, `number`, `stamp` |
| `range` | дальность/расстояние: герой на шкале, предел, клик, куда долетел, карточка игрока | `heroes[1]`, `icon`, `max`, `land`, `player{name, caption, logos[]}`; метки `ruler`, `click`, `land`, `player` |
| `notes` | патч/текст: номер версии, лист со строками-эмодзи, расшифровка | `version`, `emoji[]`, `emoji_note`, `icon`, `decoded`; метки `emoji`, `decode` |
| `grid` | число + сетка иконок | `number`, `icons`, `count`, `heroes[1]` (можно без героя — подпись встанет под сетку), `label` |

Раскладки в одном ролике не повторять; оформление от выпуска к выпуску менять (новые раскладки), не только героев — предметы, логотипы, иконки. `style` в `outro`: `cards` (по умолчанию — карточки фактов) или `follow` (крупное «Подпишись», подкол, кнопка «+» с ником, без карточек). `thumb` в `visual` (`hero:`/`item:`/`file:`) — картинка факта в финальной карточке. `pad` в выпуске — пауза после фрагмента (по умолчанию 0.7 с). Новую раскладку добавлять в `facts_video.html` (построение в `init`, анимация в `drawExtra`) и проверять локально.

## Файлы

- `facts_video.py` — подготовка (озвучка, выравнивание субтитров, картинки), рендер кадров, звук, режим дублей.
- `facts_video.html` — шаблон: стили, раскладки, анимации, проверка раскладки `audit()`.
- `episodes_fv/` — выпуски. `voice/` — выбранные дубли. `assets/` — логотипы команд/турниров, иконки способностей. `fonts/` — шрифты.
- `scene.js`, `scene.css` — сцены из JSON (SCENES.md); `dota_map.js` — материалы карты для 3D-площадки в браузере.
- `covers/` — обложки выпусков (HTML-исходники и PNG).
- `tools/` — извлечение файлов игры (`vpk_tool.py`, `dota_export.py`, `map_crop.mjs`) и текстуры.
- `tools/dota_engine/` — 3D-ролики прямо в движке доты: мод с режиссёром сцен, перевод своих анимаций в формат игры, запись.
- `tools/blender/` — те же сцены в Blender (запасной путь).
- `.github/workflows/render.yml` — рендер (push) и дубли озвучки (ручной запуск с `takes`). Нужен секрет `FISH_API_KEY`.
- `.github/workflows/assets.yml` — скачать героев, предметы, способности, логотипы (OpenDota, Liquipedia) в ветку `assets`.

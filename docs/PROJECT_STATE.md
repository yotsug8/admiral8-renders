### Исполнение и ограничения

- Основной узел снова доступен. С другого компьютера приняты CLI аудита
  нейтрали и исследование сохранения относительных shape keys при смене
  весов; оба независимо повторены локально. 18 сочетаний морфов сохранены
  в опорной позе, другие позы не гарантируются. См. NEUTRAL_AUDIT_REPRODUCIBILITY
  и RELATIVE_SHAPE_SKIN в studies. Проверенная новая анимация героя ещё не готова.

- Готовые группы медиа передавать в отдельный чат результатов, без логов
  и планов; локальный маршрут `_game/study/reporting_channel.json`.
- Один тяжёлый GPU-рендер на основном ПК; независимые лёгкие проверки
  выполнять параллельно в пределах его ресурсов. Проверять PID и артефакты,
  а не только сообщение/idle. Дополнительных компьютеров в очереди нет.
- `tools/skit/run_verified.py` проверяет свежую папку, место, exit code,
  ожидаемые файлы и SHA256; качество изображения/звука не подтверждает.
  По умолчанию резерв 2ГиБ, для большого рендера нужен больший расчётный запас.
- На системном томе меньше 1ГиБ свободно на последней проверке: длинные
  рендеры не запускать. Завершённые `chase_finish/frames_full` перенесены
  на другой том с SHA256-сверкой; старый путь — junction. Точные маршруты
  и manifest в `_game/storage_relocations.json`, учитывать при backup.
- `_game`/кэш/примеры не входят в main. Внешние файлы — LOCAL_FILES.md.
  Не публиковать игровые модели, личные пути и локальные журналы.
- Чужие производственные изменения не коммитить. Общий `check.py` проверяет
  планирование/раскладку, не весь Blender-код; узкие проверки выполняются
  отдельно. Общий check.py прошёл; 7 проверок защиты запуска и 2 проверки
  межпроцессной блокировки прошли. Проверка Blender выполнена отдельно.

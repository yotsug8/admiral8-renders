# Бросок: подготовка, дуга и доведение движения

Четырёхсекундное учебное сравнение, 30 fps, 960×1080. Сверху —
механический контроль, снизу — замах, работа корпуса и продолжение
движения руки после отпускания. Полёт мяча одинаковый; сравнивается
актёрское движение, а не скорость воспроизведения. Без звука и надписей.

Результат: `foundation_throw_comparison.mp4` в ветке renders.
Это упражнение на процедурном манекене, не готовая игровая сценка.
Нет пальцев, кожи, измеренной массы или физической модели равновесия.

## Принципы в действии

- Подготовка: 0,30–0,90 с, отведение руки и небольшой наклон назад.
- Дуга: 0,90–1,40 с, кисть проходит над плечом. Прямой проход рядом
  с плечом был отклонён: плоскость сгиба локтя быстро разворачивалась.
- Тайминг: спокойная подготовка, более быстрое действие, удержание после.
- Доведение: после отпускания в 1,40 с кисть продолжает движение,
  корпус принимает усилие; возврат завершается к 2,65 с.
- Постановка: боковой план показывает замах и выпуск; в 3/4 эти фазы
  сильнее перекрывались корпусом. Второй ракурс оставлен для проверки.

Используются геометрия и двухзвенный решатель из `study_lift.py`.
Новая универсальная система скелета не создавалась. Траектория мяча
задана баллистическими участками; коэффициенты отскока/трения выбраны
для демонстрации, не измерены для конкретного материала. Времена касаний
добавлены отдельными ключами, чтобы интерполяция не срезала удар о пол.

## Проверка

Две сцены сохранены и открыты заново. На каждую — 953 независимых
субкадровых отсчёта: воспроизведение координат, длины сегментов,
совпадение концов сегментов с суставами, дистанция мяча от кисти,
пол/тело/голова, запас кадра в двух камерах.

Для варианта с подготовкой: ошибка координат до 0,513 мм, разрыв
концов сегментов до 1,193 мм, длины до 0,001 мм; пересечения мяча с
проверенными капсулами корпуса/ног/головы не обнаружены, запас кадра
не менее 4,15%. Это ограниченные капсульные проверки, не полный поиск
самопересечений всех деталей. Стопы статичны; перенос физического центра
масс не рассчитывался.

Просмотрены ключевые кадры с двух сторон и все 120 кадров сравнения
на шести листах. Декодированный MP4 сверён с обоими источниками
покадрово; максимальная средняя ошибка кодирования — 1,058 из 255.
Перенос на другой rig, другая дистанция, другой вес и художественная
приёмка пользователем остаются отдельными следующими проверками.

## Повторение

Из корня проекта, Blender 5.2.3 LTS. Для build нужны новые папки;
для render — ранее проверенные build. Одновременно один GPU-процесс.

```powershell
blender -b --factory-startup --disable-autoexec --python-exit-code 2 `
  -P tools/blender/study_throw.py -- --out _game/study/throw/mechanical --case mechanical
blender -b --factory-startup --disable-autoexec --python-exit-code 2 `
  -P tools/blender/study_throw.py -- --out _game/study/throw/staged --case staged
# Просмотреть пробные кадры; затем для обеих папок тот же вызов с --mode render.
py -3.11 tools/skit/assemble_throw.py --mechanical _game/study/throw/mechanical `
  --staged _game/study/throw/staged --out _game/study/throw/comparison
```

`--mode audit` повторяет проверки сохранённой сцены без рендера.
Основная локальная проверенная версия — папки `mechanical_final`,
`staged_final`, `comparison`; результаты измерений — их `audit.json`/`qa.json`.

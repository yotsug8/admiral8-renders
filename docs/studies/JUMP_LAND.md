# Прыжок вперёд и мягкое приземление

Повторяемая кинематическая проба жёсткого манекена без игровых ресурсов:
`tools/blender/study_jump_land.py`. Одна анимация, два неподвижных ракурса
(профиль и спереди ¾), 3,5 с, 105 кадров на ракурс, 640×360, 30 fps,
без звука. Это учебная проба контактов и тайминга, не физическая симуляция.

## Использованные решения

Перед реализацией прочитаны `jump_motion.py` и `study_bounce.py`.
Из первого непосредственно используются `plan_jumps` (время полёта,
скорость отрыва/удара, длительность подготовки и амортизации) и
`refine_jump_roots` (баллистическая вертикальная FCurve с точными
касательными между ключами). Сжатие сфер из `study_bounce.py`
не переносится на конечности: оно меняет форму тела и не решает контакт стоп.

Геометрия, материалы, двухзвенный решатель и ключи — `study_lift.py`;
схема сегментов и извлечение вычисленной геометрии — `study_step_touch.py`;
расстояния между капсулами — `study_pointing.py`. Новые зависимости не нужны.

## Действие

| Время, с | Действие |
|---|---|
| 0–0,25 | Исходная стойка |
| 0,25–0,80 | Присед на 0,24 м и отведение рук |
| 0,80–0,90 | Короткая подготовка, начало взмаха |
| 0,90–1,10 | Разгибание с выходом на скорость отрыва |
| 1,10–1,70 | Единственный полёт, вершина в 1,40 с |
| 1,70–1,85 | Сгибание после контакта, просадка таза на 0,24 м |
| 1,85–2,55 | Плавное восстановление |
| 2,55–3,50 | Удержание конечной стойки |

В свободном полёте **таз** проходит одну параболу при g=9,81 м/с²,
высоте 0,44145 м и горизонтальной скорости 1 м/с. Скорость по вертикали
при отрыве/касании ±2,943 м/с. Это выбранная опорная точка анимации,
а не рассчитанный центр масс. Стопы переносятся на 0,70 м и дополнительно
поджимаются на 0,10 м в середине полёта.

До отрыва и после посадки обе плоские подошвы закреплены. Присед и выход
из него решаются движением таза и сгибом ног при постоянных длинах.
Вход в полёт и начало амортизации используют кубическую интерполяцию
с заданной скоростью таза. У стоп при ударе скорость обнуляется;
механика давления, пятки и носка не моделируется.

## Повторение

Из корня репозитория, с путями к существующим Blender и FFmpeg в переменных:

```powershell
& $env:BLENDER -b --disable-autoexec --python-exit-code 2 -P tools/blender/study_jump_land.py -- --out _game/study/jump_land/build_new --mode build
& $env:BLENDER -b --disable-autoexec --python-exit-code 2 -P tools/blender/study_jump_land.py -- --out _game/study/jump_land/block_new --mode block
& $env:BLENDER -b --disable-autoexec --python-exit-code 2 -P tools/blender/study_jump_land.py -- --out _game/study/jump_land/render_new --mode render --ffmpeg $env:FFMPEG
& $env:BLENDER -b --disable-autoexec --python-exit-code 2 -P tools/blender/study_jump_land.py -- --out _game/study/jump_land/render_new --mode review --ffmpeg $env:FFMPEG
```

`build` строит, сохраняет, повторно открывает и проверяет сцену, включая
отрицательные пробы, без рендера. `block` выводит кадры 0, 24, 33, 42,
51, 56, 80 с обеих камер. `render` рассчитывает полные последовательности
и кодирует MP4. `review` открывает существующий `.blend`, повторяет проверки
и отрицательные пробы, декодирует оба MP4 и создаёт листы всех кадров.
Новая папка обязательна во всех режимах, кроме `review`.

Настройки рендера: Cycles CPU, 16 samples, denoise, фиксированный seed=0,
AgX. Используется Blender 5.2.0 LTS. Предупреждения о невозможности записи
пользовательского кэша/миниатюры не помешали сохранению и повторному открытию
сцены. Общий `tools/check.py` на этом компьютере не повторяется: его
недостающие зависимости известны, полный прогон выполняется на основном ПК.

## Проверка сохранённой анимации

Ключи суставов записаны с шагом 1/8 кадра; проверка реально вычисленных
мировых матриц после повторного открытия идёт с шагом 1/16 кадра:
1665 отсчётов. Проверяются реальные четыре нижние вершины каждой подошвы
после модификатора bevel, все вершины стоп на провал, концы жёстких
сегментов и их соответствие суставам. Для остальных частей используется
консервативная нижняя граница сфер/капсул. Камеры проверяются на каждом
целом кадре по границам геометрии. Самопересечения проверяются только
для капсул рук относительно корпуса, головы и ног.

| Метрика | Результат |
|---|---:|
| Дрейф подошв при подготовке | 7,45×10⁻⁹ м |
| Дрейф подошв после посадки | 5,96×10⁻⁸ м |
| Максимальная ошибка длины | 1,72×10⁻⁶ м |
| Расхождение концов сегментов и суставов | 0,388 мм |
| Минимальная высота проверенных поверхностей | 0 м |
| Ошибка баллистической траектории таза | 1,34×10⁻⁷ м |
| Минимальный зазор подошв на внутренних отсчётах полёта | 6,13 мм |
| Ошибка кривой амортизации | 0,054 мм |
| Минимальный зазор проверенных капсул рук | 44,94 мм |
| Разница соседних оценок скорости таза у отрыва / посадки | 0,0386 / 0,0227 м/с |
| Минимальное поле кадра: профиль / ¾ | 4,28% / 3,55% |
| Число интервалов полёта | 1 |

Зазор 6,13 мм относится к дискретным внутренним отсчётам: у самих
границ полёта он стремится к нулю. Конечная разность скорости имеет шаг
1/480 с и не является доказательством нулевого скачка производной.
Интерполяция конечностей допускает небольшую субкадровую погрешность;
баллистическая вертикальная кривая уточнена отдельно.

Отрицательные пробы изменяют реальную сохранённую геометрию/FCurve:
смещение опорной стопы, провал стопы, удлинение голени, контакт одной
стопы во время полёта и отклонение свободного полёта от параболы.
Для каждой требуется отказ по соответствующей метрике. После восстановления
всех каналов выполняется ещё одна успешная проверка; испорченная сцена
не сохраняется.

## Визуальная оценка и границы результата

Просмотрены два набора ключевых поз. Во втором руки опущены ниже в стойке,
взмах начинается раньше, ракурс ¾ перенесён вперёд. Попытка направить локти
сильнее вниз отвергнута численно до рендера: пересечение корпуса, затем
слишком быстрый поворот сгиба. В итоговой версии сохранён устойчивый
исходный ориентир локтей. Пороги проверок не ослаблялись.

Подготовка, отрыв, перенос вперёд и присед после контакта различимы.
Манекен остаётся стилизованным: руки разведены, стопы плоские, нет
переката через носок, пальцев, кожи, одежды, масс, равновесия или звука.
Профиль частично перекрывает дальние конечности; ракурс ¾ показывает
обе стопы. Эти ограничения не выдаются за освоение физического прыжка
или перенос результата на игровой rig.

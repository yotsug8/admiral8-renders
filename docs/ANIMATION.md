# Анимационные сценки (Blender на настоящей карте доты)

Формат «говорящие герои»: крупные лица, мимика, жесты, звук ведёт ролик, мягко размытый фон, свет, монтаж восьмёркой. Логику (кто где, реплики, планы) считает площадка, картинку рендерит Blender. Нужен ПК с дотой, S2V и Blender 5.2.

## Одной командой
```
py -3.11 tools/skit/skit.py skits/<имя>.txt            голоса, scene.json, пробы (кадр середины каждого плана, лист probe.jpg)
py -3.11 tools/skit/skit.py skits/<имя>.txt --all      весь ролик: кадры → mp4 → сведение (mix.py, GRADE=1)
py -3.11 tools/skit/skit.py skits/<имя>.txt --plan     только голоса и scene.json
py -3.11 tools/skit/skit.py skits/<имя>.txt --dota     ещё сцена для движка доты: анимации разговора в DMX, те же планы автокамерой
py -3.11 tools/skit/skit.py skits/<имя>.txt --blend    сцена в Blender для ручной правки: _game/skits/<имя>/<имя>.blend (откроется сам; --no-open — нет)
```
Всё складывается в `_game/skits/<имя>/`. Сначала пробы, полный рендер — после «ок» (~2,5 с на кадр).

## Сценарий
```
название: kryuk
карта: radiant_field                      кусок карты _game/maps/<имя>.glb; без строки — плоская земля
герой pudge -4250 -3220                   актёр = герой в точке карты; «герой pudge2 pudge x y» — второй такой же
герой sniper -3350 -3220 стойка sniper_idle_aggressive
голос sniper sapi=Pavel fish=<id> edge=ru-RU-DmitryNeural
sniper: Реплика. | эмоция | вверх/вниз | крупно/через плечо
pudge > крюк sniper                       действие (сейчас одно — крюк)
```
- Реплики идут подряд по длине озвучки (паузы 0,4 с, у того же героя 0,25 с). Склейка — за 0,15 с до голоса и не раньше конца прошлой реплики.
- Планы сами: первый — через плечо говорящего, дальше крупно говорящего, на действие — через плечо действующего, после — через плечо цели. Свой план — меткой.
- Эмоции — словарь `EMO` в skit.py (веса морфов лица); своя реплика — в полную силу, потом держится вполсилы.
- Числа: `{1300|тысяча триста}` — в субтитрах первое, голос читает второе.

## Голоса (`tools/skit/voices.py`)
Fish Audio (если есть `FISH_API_KEY`) → робот Windows → edge-tts; `SKIT_FAKE=1` — гул для проверки без голоса. Каждая реплика распознаётся (faster-whisper) и сверяется с текстом — «⚠ ГОЛОС НЕ СОВПАЛ» при совпадении ниже 60 % (до 26.10 робот Windows читал кракозябры: текст шёл через stdin PowerShell в кодировке консоли — звук проб №1–3 бессмысленный). Русский мужской голос Windows один (Павел) — разные герои: `голос sniper sapi=Pavel pitch=3` (сдвиг тона, полутоны). edge-tts с 26.10 не отдаёт звук (403 / No audio). **Голос героя на любой текст — `голос sniper ref=sniper`**: мгновенное клонирование Fish по ~22 с спокойной речи героя из его русской озвучки (`game_vo.reference`, образец в `_game/vo/ref_<герой>.wav`), бесплатная модель `s2.1-pro-free` — своя модель на Fish требует баланса API («limit 0/0»), голоса из библиотеки Fish по названию «Снайпер» — из Team Fortress 2 (участник: «не тот снайпер»). Ключ Fish читается и из настроек Windows (после `setx` перезапуск не нужен). Настоящие реплики героев из русской озвучки: `py -3.11 tools/skit/game_vo.py pudge` (выгрузка в `_game/vo/` + каталог с текстом), в сценарии `| реплика pud_ability_hook_09`, поиск — `game_vo.py find pudge мясо`. Тишина по краям обрезается. `voices.json`: `text` (субтитры), `say` (как произносится — по нему губы), `env` (громкость 30 раз в секунду), `dur`. Готовые реплики не переозвучиваются.

## Герои
- `py -3.11 tools/dota_engine/troupe.py <герои>` — сведения в `_game/data/troupe.json` (рост, голова, челюсть, стойка). Челюсть-кость есть не у всех: без неё говорит головой.
- Модели для рендера — `_game/models/render/*.glb`: выгрузка S2V с `--gltf_export_materials --gltf_textures_adapt`, текстуры рядом PNG.
- Одежда — как bone merge: кости части повторяют кости тела (Copy Transforms), иначе части отрываются.
- Материалы (`fix_hero_mats`): S2V кладёт в прозрачность, металличность и блик (Specular IOR Level ← specmask) маску доты — ставить непрозрачно, не металл, roughness 0,62, блик 0,2 без связи. Связь блика со specmask давала серый налёт на всём герое («выцветшее», насыщенность кожи 0,2 при текстуре 0,43).
- Рот на крике (`mouth_dark`): рот у голов доты не прорезан — губы соединены гранями, jawOpen растягивает их в светлые полосы. Грани, которые jawOpen растягивает больше чем вдвое, темнеют (атрибут углов граней, материал головы — своя копия). Вставки в голову (тёмный шар, копия головы) не годятся: шар виден как шар.
- Шея (`close_neck`): голова и тело у героев доты — отдельные сетки, под подбородком щель (игра смотрит сверху и её не видит). Нижняя кромка головы соединяется с телом перемычкой на костях тела; крупный план — с уровня глаз, разговор — на обычной стойке (портретная задирает голову). «Исправлено» — только после увеличенного сравнения с кадром доты.
- Глаза Пуджа белые без зрачков — так в игре (участник), не менять.
- Мимика (`tools/blender/face.py`): у голов есть морфы FACS доты (брови, веки, взгляд, щёки, губы, jawOpen, phonemeBMP/FV). Речь — буквы реплики по времени звучания → формы рта, раскрытие на громкость; эмоции — `faces` сцены; моргание и взгляд — сами. Кость челюсти при этом вполсилы.
- Разговор телом (`tools/blender/skit_talk.py`): стойка, кивки на ударениях, челюсть по громкости, настроение головы (вверх/вниз), без рывков (сглаживание 0,25 с, качание стойки приглушено).

## Рендер (`tools/blender/render_scene.py -- <scene.json> <папка кадров> [all | 75,150] [half]`)
- Планы (`shots`): `close` — голова и плечи (size 0,85 роста, fov 34, 35° от лица, камера на уровне глаз), `over` — через плечо: передний у края кадра (xf), дальний по другую сторону (xb), отступ назад подбирается под объектив (fov 24–30 сжимает расстояние). Камера всегда по одну сторону от линии героев.
- Луч к героям проверяется: деревья на нём убираются на время плана, камни и здания — другой вариант камеры.
- Свет плана: мягкий ключевой у камеры и холодный контровой за героем; камера «с рук», размытие фона на герое плана.
- Тон: **Khronos PBR Neutral** (AgX гасил цвет: кожа Пуджа — сила цвета 18 против 41 у Пуджа в примере dotaroot, оттенок бежевый 45° против 40°; участник: «то ли оттенок, то ли засвет»), экспозиция 0, солнце 3 (мягкая тень, угол 10°), заднее солнце 1, контровой 200 Вт, рассеянный свет неба на героях 1,5 (участник: «тени зачастую портят кадры» — тени заливать, как в доте) (участник: «на Пуджа падает свет — белое пятно на волосах»: холодное заднее солнце 4,2 и контровой 600 выбеливали края плеч и макушку, солнце 4 — висок; глаза и зубы белые в модели — не трогать, искать только блики), раньше — солнце 4, ключевой 300 Вт, контровой 600 Вт (участник выбрал из вариантов: «чёткие цвета без засвета» — мнение, не идеал; ключевой 1500 Вт выбивал кожу Пуджа в белый, AgX уводит яркое в белый); небо в кадре яркое, а на героев светит тёплее и слабее (`amb` 0,6 — голубой свет неба делал кожу сиреневой) (`A8_LOOK="expo=…;key=…"` — подбор на пробах). Проверять гистограммой: средняя яркость 74–109, насыщенность ~0,45, выбитых белых нет. Свечение — слабое, в сведении (GRADE): композитор Blender 5 недоступен (`Scene.node_tree` убран).
- Весь ролик рендерится анимацией: готовые кадры пропускаются — после сбоя запуск продолжает с места (`A8_REDO=1` — заново); два Blender на одну папку делят кадры.
- Пути — абсолютные (относительные Blender пишет от корня диска).
- `sc.frame_set` внутри цикла ключей сбрасывает камеру к записанным ключам — всё, что считается через frame_set, считать до установки камеры.

## Руками в Blender (`--blend`)
Файл сцены: герои с одеждой, анимации дорожками NLA, мимика ключами морфов, камера и свет по планам, голоса дорожками звука (воспроизведение со звуком).
- Пробел — проиграть; Num 0 — вид из камеры; F12 — кадр; Ctrl+F12 — весь ролик в папку frames (Свойства вывода — путь).
- Поза: выбрать скелет героя (`…pudge.vmdl_c`), Ctrl+Tab — режим позы, кость — R поворот, G сдвиг; I — ключ. Свои ключи ложатся поверх готовых анимаций (только на тронутых костях).
- Лицо: выбрать голову (`…pudge.vmdl_c.head`), Свойства данных (зелёный треугольник) → Shape Keys: ползунок морфа, навести и I — ключ.
- Камера ключится на каждом кадре (склейки): правка — встать в кадр, сдвинуть камеру, I; ключи соседних кадров плана удалить или сдвинуть так же.
- Готовые кадры → ролик: `ffmpeg -framerate 30 -i frames/f%05d.png …`, потом `tools/skit/mix.py <видео> <выход> <scene.json>` (голоса и субтитры).

## Эталон — примеры участник (обучение)
Цель сейчас — не ролики, а научиться делать анимации уровня примеров. **Примеры — ориентир, как примерно должно выглядеть, а не образец для копирования один в один** (участник, проба №1): брать из них уровень — крупность, живость, мимику, свет, — а план, ракурс, движение и подачу придумывать свои под реплику и героя; цифры ниже — рамки, а не цель попасть точно. **Странные анимации — это смешно** (участник): Пудж идёт в Т-позе, лицо искажается сильнее, чем бывает, под ситуацию и другие нелепые варианты — приём, а не ошибка, если стоит в смысловом месте. Перед показом крупно проверять кисти (оружие в руке), ноги (не вывернуты, на земле) и край кадра (нет изнанки карты) — участник: «исправляй сразу очевидные вещи» (проба №5: Т-поза сбрасывала все кости — ноги выворачивались, тесак отрывался; камера на общем плане уходила под землю). Ходьба своя: метка `идёт N` (идёт к собеседнику N единиц, пока говорит; шаг — бедро, колено на выносе, стопа ровно, руки в противоход, частота от скорости и длины ноги), `камера стоит` (камера от точки, куда герой приходит). Стопы ставятся на землю по стойке (Т-поза выпрямляет ноги — без этого висел в воздухе); шаг применяется после жестов. Инструменты: `жест тпоза` (всё тело в позу скелета по умолчанию), `жест парит` (висит в воздухе, тело застыло), `жест выгнуться` (дуга назад, руки заломлены), `жест скрутиться` (корпус и голова в разные стороны), `жест дрожь`, `утрировать N` (морфы лица за 1 — гротеск; рот не шире `JAW_CAP`). **Анимации — свои** (участник): позы и жесты делать самим ключами костей (`skit_talk.py`, `GESTURES`, метка `жест <имя>`), игровые анимации — только если к месту (стойка, бег). Руку ставить прицелом (`aim`: кисть на направление), а не поворотами по осям — стойки у героев разные. Сами примеры (9 роликов участник) лежат в `_game/study/examples/`. Разбор: `py -3.11 tools/skit/study.py <папка|mp4…>` → листы кадров и цифры в `_game/study/` (примеры — `metrics_examples.json`). Свои пробы мерить так же и сравнивать.
- Цифры 9 примеров (медиана): ролик 10–25 с; план 1,5–5 с там, где есть склейки (часть роликов — один план с движением); яркость 75 (25–130), насыщенность 0,41, контраст 52; **движение в кадре 6,3 (90-й процент 17,6) — у «Крюка» 3,9 / 9,6: мы в 2 раза статичнее**.
- Лицо крупно: голова занимает 50–80 % ширины кадра, часто обрезана краем (макушка, подбородок); у нас ~35 %.
- Широкий объектив вплотную, часто снизу на фоне неба (solevix, arbuzprodota — «селфи»: герой качается к камере и от неё, наклоняет голову).
- Мимика утрирована: рот на громком слове раскрыт до предела, брови и глаза работают на каждую фразу; голова и плечи всё время в движении (но плавно — не рывками).
- Через плечо: передний герой огромный и размытый, занимает треть кадра (avulus).
- Фон: яркое небо и зелень, сильное размытие; цвет насыщенный, без белёсости.
- Монтаж бывает очень быстрым (SFM-сценка в таверне: 10 склеек за 14 с, план 1,3 с): быстрые белые вспышки-переходы, чёрно-белое «воспоминание», интерьер вместо открытой карты, интерфейс игры над героями (полоски здоровья, уровень) — как шутка. Насыщенность 0,63.
- Как делают такие ролики (рассказ venskorp): модель — S2V в glTF (как у нас); риг руками или Rigify; свои шейдеры кожи и волос (волосы — обычная текстура плюс шум), **глаза сделаны с нуля** (у нас белёсые глаза Пуджа — то же место); анимация по видео-референсу кадр за кадром; свет и место ставятся отдельно; дым и атмосфера — на постобработке.
- Вторая партия (4 примера 26.10: badblood__666, ultra_hd_ken, 1loxxy, dotaroot; цифры — `_game/study/metrics_examples2.json`): ролик 6–17 с, история склейками — завязка → реакция → развязка, план 2,4–4 с; крупные лица вперемешку с общими и средними планами (герой во весь рост в месте действия) и вставками предмета-шутки (коробка, шляпа, иконки предметов игры); **камера в основном спокойная — движение в кадре 2,9 (у первой партии 6,3), живость дают сами герои**; развязка часто входит из-за края кадра (тесак Пуджа влетает в лягушку); светло и солнечно — яркость 113, насыщенность 0,45, тёплое небо на закате.
- Новые образцы класть туда же, в `_game/study/examples/` (имя = автор и что на нём). Из облачного чата упоминались venskorp_как_делают_анимацию и gigabyte_таверна_sfm — на ПК их нет (выводы по ним выше записаны).
- Обучение: короткие пробы по одному навыку (крупность, движение, мимика, свет), участник ставит оценку и одну фразу — фраза становится правилом здесь.
- Проба №1 (`skits/probe_pudge.txt`, план `селфи`, «ухмылка → крик»): голова 61–81 % ширины, яркость 109, насыщенность 0,40, движение 8,1, поворот головы за кадр ≤1,3° без скачков. Минус: на крике внутри рта растянутая кожа вместо тёмного горла. Ответ участник — правило о примерах выше (не копировать один в один).
- Проба №2 (`skits/probe_pudge2.txt`, план `наезд`: вполоборота на уровне глаз, объектив 40°, на смене эмоции наезд от плеч к лицу, камера спокойная): яркость 77, насыщенность 0,45, движение 5,9, голова 36→83 % ширины. участник: «почему шар во рту», «всё выцветшее» — исправлено (см. «Мимика», «Материалы»). Оценка **4/10 по сравнению с примерами**. Разница (кадры рядом — `_game/skits/probe_pudge2/vs_examples.jpg`):
  - свет: в примерах — солнце, у лица ясная светлая сторона и форма, тёплый закат; у нас лицо в тени, свет плоский и мутный, тени сиреневые;
  - фон: в примерах светлый и читаемый (трава, небо, деревья), размыт слегка; у нас тёмные пятна деревьев на треть кадра и серые развалины;
  - чистота картинки: в примерах гладко и чётко; у нас зерно и мыло (24 сэмпла, половинный размер), растянутая текстура рта;
  - рот: в примерах раскрыт внутрь — тёмное горло, зубы; у Пуджа рот не прорезан — на крике кожа рвётся полосами; jawOpen держать в пределах, где модель не ломается, крик играть телом;
  - игра телом: в примерах поза говорит сама (Дроу запрокинула голову от смеха, Эртшейкер с кулаком вперёд, жаба целиком у коробки); у нас голова и плечи без жеста;
  - кадр: в примерах герой вписан с позой и жестом; у нас голова зажата, края кадра забиты размытыми плечами.
- Проба №3 (`skits/probe_pudge3.txt`) — всё по разбору: солнце плана спереди-сбоку от камеры (светлая сторона лица), низкая камера на небо и ели, средний план `средний` (герой по колено, f/4 — фон читается), свой жест `крюк` (рука прицелом вскидывает крюк, лицо открыто), рот у Пуджа не шире 0,55 (`JAW_CAP`), полный размер и 64 сэмпла (`A8_SAMPLES`, 13 мин на 113 кадров). Цифры: яркость 83, насыщенность 0,43, движение 6,0, голова 30 % ширины. участник: «не могу оценить, пока нет нормальной цветокоррекции — картинка другая и хуже». Замер в Lab показал: тени провалены (25-й процентиль яркости 5–8 против 31–36 у примеров), цвет в полутонах вдвое слабее (chroma 18–20 против 28–42), полутона холоднее. Старая метрика «насыщенность» (study.py) этого не видела — цвет мерить в Lab (`grade.py`). После `GRADE=match`: процентили яркости 3/9/29/52/70/86/96 (примеры 4/13/34/57/70/87/99), chroma полутонов 27. участник: «засвечено сильно» — коррекция по образцу на полную силу поднимала середину (32→53), а свет на герое выбивал кожу; теперь сила 0,4 и свет слабее. Белое коррекцией не вернуть — пересвет исправлять светом в рендере. Кожа героев в текстурах доты блёклая (сила цвета ~17) — игровой шейдер её досыщает; в `grade.py` цвет поднимается отдельно от яркости (`color` 1,0 при яркости 0,4; участник о PBR Neutral + коррекции: «понасыщенней выглядит лучше»), тёплые оттенки на 4° к красному. Света (яркость > 70) коррекция не поднимает — блики не выбеливаются. Блики искать маской (Lab: яркость > 82, цвет < 18) по всей длине, кроме глаз, зубов и белой краски. Сверять с тем же героем в примере (замер кожи: яркость, сила цвета, оттенок в Lab).

## Карта
- Кусок: `node tools/map_crop.mjs _game/world/world.gltf _game/maps/<имя>.glb <glTF x = игра y/39.37> <glTF z = игра x/39.37> <радиус м>`; мир выгружает `tools/blender/export_world.bat`.
- Материалы — `tools/blender/dota_map.py` (земля смешивается из слоёв как в игре). Он сам чистит выгрузку: варианты листвы `tree_magical*`/`tree_blossoms*`, карточки `glow_*`, висящие куски скал.
- Оси в Blender: x = игра y, y = −игра x; поворот героя — как в доте.
- Граница вырезанной карты не должна попадать в кадр: радиус больше или камера спиной к краю. участник: «разберись с фоном, чтобы полностью отрисовывался» — кусок 75 м кончался за деревьями (пустой горизонт, обрывки забора), теперь `radiant_wide` 180 м (222 МБ, загрузка в Blender ~5 мин).
- Фон (участник: «плоховато выглядит»): дымка по расстоянию до камеры в материалах карты (`fog`, от 40 до 280 м — тусклее и голубее, светится в самой поверхности, прозрачность листвы сохраняется; объёмный туман гасил солнце и небо, смешивание с излучением давало «снег» на листьях), горизонт светлее и теплее (`horizon`). Сведение фона с героями (участник: «подкорректируй фон по освещению, контрасту, цвету»): листва и земля карты были темнее и холоднее (сине-зелёные) героев — `bg_gain` 1,55, `bg_warm` 0,04 (зелень к жёлтому), `bg_sat` 1,2; ели тёмные текстурой.

## Сведение (`tools/skit/mix.py <видео> <выход> <scene.json>`)
Голоса по местам, −14 LUFS, субтитры канала (Manrope из woff2 через Chromium, страница из файла). `GRADE=match` (по умолчанию в `skit.py --all`) — цвет по примерам (`tools/skit/grade.py`): кривая яркости под процентили дневных примеров, цвет в тенях/полутонах/светах до их уровня (мягкий потолок — яркое не кислотное), полутона теплее; одна кривая на ролик. `GRADE=1` — старое: свечение, виньетка, контраст.

# Анимационные сценки (Blender на настоящей карте доты)

Формат «говорящие герои»: крупные лица, мимика, жесты, звук ведёт ролик, мягко размытый фон, свет, монтаж восьмёркой. Логику (кто где, реплики, планы) считает площадка, картинку рендерит Blender. Нужен ПК с дотой, S2V и Blender 5.2.

## Одной командой
```
py -3.11 tools/skit/skit.py skits/<имя>.txt            голоса, scene.json, пробы (кадр середины каждого плана, лист probe.jpg)
py -3.11 tools/skit/skit.py skits/<имя>.txt --all      весь ролик: кадры → mp4 → сведение (mix.py, GRADE=1)
py -3.11 tools/skit/skit.py skits/<имя>.txt --plan     только голоса и scene.json
py -3.11 tools/skit/skit.py skits/<имя>.txt --dota     ещё анимации разговора в DMX и сцена для движка доты
```
Всё складывается в `_game/skits/<имя>/`. Сначала пробы, полный рендер — после «ок» (~2,5 с на кадр).

## Сценарий
```
название: kryuk
карта: radiant_field                      кусок карты _game/maps/<имя>.glb; без строки — плоская земля
герой pudge -4250 -3220                   актёр = герой в точке карты; «герой pudge2 pudge x y» — второй такой же
герой sniper -3350 -3220 стойка sniper_idle_aggressive
голос sniper sapi=Pavel fish=<id> edge=ru-RU-DmitryNeural
sniper: Реплика. | эмоция | вверх/вниз | крупно/через плечо
pudge > крюк sniper                       действие (сейчас одно — крюк)
```
- Реплики идут подряд по длине озвучки (паузы 0,4 с, у того же героя 0,25 с). Склейка — за 0,15 с до голоса и не раньше конца прошлой реплики.
- Планы сами: первый — через плечо говорящего, дальше крупно говорящего, на действие — через плечо действующего, после — через плечо цели. Свой план — меткой.
- Эмоции — словарь `EMO` в skit.py (веса морфов лица); своя реплика — в полную силу, потом держится вполсилы.
- Числа: `{1300|тысяча триста}` — в субтитрах первое, голос читает второе.

## Голоса (`tools/skit/voices.py`)
Fish Audio (если есть `FISH_API_KEY`) → робот Windows → edge-tts; `SKIT_FAKE=1` — гул для проверки без голоса. Тишина по краям обрезается. `voices.json`: `text` (субтитры), `say` (как произносится — по нему губы), `env` (громкость 30 раз в секунду), `dur`. Готовые реплики не переозвучиваются.

## Герои
- `py -3.11 tools/dota_engine/troupe.py <герои>` — сведения в `_game/data/troupe.json` (рост, голова, челюсть, стойка). Челюсть-кость есть не у всех: без неё говорит головой.
- Модели для рендера — `_game/models/render/*.glb`: выгрузка S2V с `--gltf_export_materials --gltf_textures_adapt`, текстуры рядом PNG.
- Одежда — как bone merge: кости части повторяют кости тела (Copy Transforms), иначе части отрываются.
- Материалы (`fix_hero_mats`): S2V кладёт в прозрачность и металличность маску доты — ставить непрозрачно, не металл, roughness 0,62.
- Мимика (`tools/blender/face.py`): у голов есть морфы FACS доты (брови, веки, взгляд, щёки, губы, jawOpen, phonemeBMP/FV). Речь — буквы реплики по времени звучания → формы рта, раскрытие на громкость; эмоции — `faces` сцены; моргание и взгляд — сами. Кость челюсти при этом вполсилы.
- Разговор телом (`tools/blender/skit_talk.py`): стойка, кивки на ударениях, челюсть по громкости, настроение головы (вверх/вниз), без рывков (сглаживание 0,25 с, качание стойки приглушено).

## Рендер (`tools/blender/render_scene.py -- <scene.json> <папка кадров> [all | 75,150] [half]`)
- Планы (`shots`): `close` — голова и плечи (size 0,85 роста, fov 34, 35° от лица, камера на уровне глаз), `over` — через плечо: передний у края кадра (xf), дальний по другую сторону (xb), отступ назад подбирается под объектив (fov 24–30 сжимает расстояние). Камера всегда по одну сторону от линии героев.
- Луч к героям проверяется: деревья на нём убираются на время плана, камни и здания — другой вариант камеры.
- Свет плана: мягкий ключевой у камеры и холодный контровой за героем; камера «с рук», размытие фона на герое плана.
- Тон: AgX Punchy, экспозиция +0,15 (`A8_LOOK="expo=…;key=…"` — подбор на пробах). Проверять гистограммой: средняя яркость 74–109, насыщенность ~0,45, выбитых белых нет. Свечение — слабое, в сведении (GRADE).
- Пути — абсолютные (относительные Blender пишет от корня диска).
- `sc.frame_set` внутри цикла ключей сбрасывает камеру к записанным ключам — всё, что считается через frame_set, считать до установки камеры.

## Карта
- Кусок: `node tools/map_crop.mjs _game/world/world.gltf _game/maps/<имя>.glb <glTF x = игра y/39.37> <glTF z = игра x/39.37> <радиус м>`; мир выгружает `tools/blender/export_world.bat`.
- Материалы — `tools/blender/dota_map.py` (земля смешивается из слоёв как в игре). Он сам чистит выгрузку: варианты листвы `tree_magical*`/`tree_blossoms*`, карточки `glow_*`, висящие куски скал.
- Оси в Blender: x = игра y, y = −игра x; поворот героя — как в доте.
- Граница вырезанной карты не должна попадать в кадр: радиус больше или камера спиной к краю.

## Сведение (`tools/skit/mix.py <видео> <выход> <scene.json>`)
Голоса по местам, −14 LUFS, субтитры канала (Manrope из woff2 через Chromium, страница из файла). `GRADE=1` — свечение, виньетка, контраст.

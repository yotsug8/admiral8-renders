# Admiral8 Renders

Локальная программа для сборки видео по промпту на Windows x64.

1. [Скачайте ZIP](https://github.com/yotsug8/admiral8-renders/archive/refs/heads/main.zip) и распакуйте его целиком.
2. Дважды щёлкните `Admiral8.cmd`. Первый запуск скачает около 1,8 ГБ и откроет окно.
3. Опишите ролик и нажмите «Собрать видео». Готовый MP4 открывается из приложения и сохраняется в `out/studio/`.

Можно прикрепить до четырёх фото, видео или файлов с текстом. Фото и видео задают палитру и формат кадра. Текст можно использовать как описание или точные реплики.

**Первая проба.** «Красный шар поднимается. Горизонтальный ролик на 2 секунды. Со звуковым сигналом».

**С героями Dota.** Установите Dota 2 и выберите русский язык в Steam. Попробуйте «Вертикальный диалог Пуджа и Инвокера в таверне. Они спорят, кто съел последний пирог». При первом диалоге программа скачает ещё около 4,6 ГБ.

В окне доступны 3D-сцены с предметами, монтаж таких сцен, постановка про шлюз и диалоги Пуджа и Инвокера. Сборщики 2D, правки и продолжение рендера доступны отдельно.

Для сложных постановок откройте проект в Codex и используйте [промпт для нового чата](docs/SETUP.md#промпт-для-нового-чата-codex). Разработка приложения пока приостановлена.

# Локальные файлы для переноса

Git хранит код, сценарии и инструкции. Для продолжения работы с теми же
моделями и материалами дополнительно переносится следующий набор из корня проекта:

| Путь | Содержимое |
|---|---|
| `_game/models/` | Модели героев, части, анимации и текстуры; переносить вместе, включая `render/` |
| `_game/maps/` | Подготовленные площадки `.glb` |
| `_game/world/` | Выгруженный мир и материалы, используемые картами |
| `_game/data/` | `troupe.json`, `ground.npz`, `clear.npz`, `buildings.txt`, сведения о частях и механиках |
| `_game/vo/` | Игровые реплики, каталоги и образцы клонирования `ref_*.wav` с текстовыми метаданными |
| `_game/sfx/` | Звуки действий и их сведения |
| `_game/sky/` | Текстуры неба |
| `_game/water_dist.png` | Подготовленная текстура воды |
| `_game/study/` | Видео-образцы, обзорные листы и локальные результаты разбора |
| `_game/memes/` | Локальные мемы, если они используются |
| `assets/snd/` | Локальные игровые звуки, исключённые из git |

Для сохранения текущих учебных результатов переносить также `_game/skits/`.
Там сцены, `voices.json`, WAV, сохранённые `.blend`, видео и диагностика.
Кадры и временные варианты можно восстановить, но перенос всей папки сохраняет
состояние без отбора. `_game/renders_wt` отдельно копировать не требуется:
это git worktree ветки `renders`, которую следует получить из GitHub.

Для работы в движке дополнительно перенести из установки игры:

- `content/dota_addons/admiral8/` — исходники моделей, DMX и ресурсы мода;
- `game/dota_addons/admiral8/` — собранные ресурсы и постановка.

Эти две папки не нужны для обычного фонового рендера Blender, но нужны для
сохранения локального состояния движка. Базовые файлы Dota устанавливаются
через Steam; отдельной копии `pak01_*.vpk` проект не хранит.

Необязательно переносить `cache/`, `qa/`, `_fv_work/`, `node_modules/`,
`__pycache__/` и кэши установленных программ: они создаются заново.
`cache/` можно сохранить, чтобы не скачивать и не генерировать повторно уже
подготовленные данные и озвучку. Оригиналы собственных медиа вне перечисленных
папок нужно сохранить отдельно, если сценарий ссылается на них.

Секреты и персональные настройки переносятся отдельно: `FISH_API_KEY`,
локальные `.env`, переопределения `DOTA_ROOT`, `S2V`, `BLENDER`, авторизация
GitHub. Наличие файлов не переносит эти настройки автоматически. Глобальный
RTK необязателен; для Blender MCP аддон устанавливается в Blender отдельно.

Точный пофайловый список конкретного компьютера можно сохранить локально
в `_game/transfer-files.tsv`: относительный путь, размер и категория.
Этот инвентарь и сами игровые ресурсы не публикуются в git.

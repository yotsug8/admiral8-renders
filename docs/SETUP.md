# Настройка и проверка

## Запуск на Windows

Распакуйте [ZIP проекта](https://github.com/yotsug8/admiral8-renders/archive/refs/heads/main.zip) в доступную для записи папку и откройте `Admiral8.cmd`. Нужны Windows x64 со встроенными PowerShell, curl и tar, видеокарта с поддержкой Blender и интернет для первой загрузки. Обычный запуск проходит без ключей API и прав администратора. На базовую установку отведите около 4 ГБ свободного места.

Программа скачивает переносимый Python 3.11.18, Blender 5.2.3, FFmpeg 8.1.2, библиотеки Visual C++, llama.cpp b7223 и Qwen2.5-1.5B. Версии, официальные адреса загрузки и контрольные суммы указаны в `tools/start_studio.ps1` и `tools/setup_studio.py`. При сбое повторно откройте `Admiral8.cmd`. Завершённые загрузки используются повторно.

Файлы программы и локальные ресурсы находятся в `out/studio/`. У каждой сборки своя папка. В ней сохраняются MP4, план и прикреплённые материалы. Журнал лежит рядом.

## Запросы и вложения

- Для одной автоматически собираемой сцены с предметами укажите форму, цвет, действие, формат и длительность от 2 до 6 целых секунд.
- Для монтажа перечислите до трёх сцен с длительностью каждой.
- Для разговора укажите Пуджа и Инвокера, тему, место и формат. Длительность составляет от 5 до 60 целых секунд, если реплики укладываются в это время. Чтобы задать точную реплику, начните строку с имени героя и двоеточия.
- «Прикрепить» принимает до четырёх фото, видео, TXT и Markdown. Нажатие на имя открывает файл, × убирает его. Из фото и видео используются формат и палитра. Изображение можно вставить из буфера.

Для героев требуется Dota 2 с русской озвучкой. Source2Viewer, модели текста и голоса и faster-whisper загружаются при первом диалоге. Подготовка и рендер идут на компьютере. Таверна Crownfall, персонажи и образцы голосов извлекаются из установленной игры.

Эти диапазоны относятся к запросам в окне. При ручной сборке 2D длительность задают сегменты сценария, а в Blender её определяют диапазон кадров и FPS. Можно собрать ролик короче двух или длиннее шести секунд.

## Работа через Codex на другом ПК

Откройте репозиторий как рабочую папку Codex с доступом к локальным инструментам. Для ручной постановки Dota нужны Blender, FFmpeg и установленная игра. Для оригинальных русских реплик нужна русская озвучка Dota. Промпт в Codex задаёт новую постановку. Автоматическая сборка сложных действий из окна приложения пока не реализована.

Для повторного рендера уже поставленной сцены перенесите упакованный `.blend`, WAV и `job.json` из локальной папки ролика. Используйте те же версии инструментов и команду `py -3.11 tools/blender/run_render_job.py путь/к/job.json`. Упакованная сцена может рендериться без доступа к игре. Для побайтно одинакового результата перенесите готовый MP4.

### Промпт для нового чата Codex

> Настрой этот компьютер для работы над роликами Admiral8 Renders. Используй открытый репозиторий как рабочую папку. Сначала прочитай `AGENTS.md`, текущий раздел `docs/PROJECT_STATE.md`, `docs/SETUP.md` и нужные разделы `docs/MASTER_SPECIFICATION.md`.
> Используй ТЗ для требований и приёмки, а текущее состояние и моё сообщение — для выбора работы.
>
> Проверь состояние Git и сохрани мои изменения. Найди установленные Dota 2, Blender и инструменты MP4. Для работы с игровыми ассетами проверь Source2Viewer, для русских реплик — русскую озвучку Dota. Если для запуска не хватает переносимых компонентов, подготовь их по инструкции проекта. Используй бесплатные локальные инструменты.
>
> Проверь результат короткой сборкой и полным декодированием MP4. Для последующих роликов сначала проверяй постановку, контакты и читаемость движения с рабочих камер, затем запускай чистовой рендер. Используй один GPU-рендер за раз.
>
> Разработка приложения пока на паузе. Мои запросы на ролики выполняй вручную через Codex. Готовые ролики, редактируемые сцены и отчёты сохраняй локально. Для публикации, расходов и существенных изменений системы сначала получи разрешение. В конце скажи, что заработало, где лежит проверочный MP4 и чего ещё не хватает.

## Техническая проверка

После первого запуска выполните в PowerShell из корня проекта. Выберите новую папку для отчёта.

```powershell
$tools = (Resolve-Path 'out/studio/bootstrap').Path
$projectPython = Join-Path $tools 'venv/Scripts/python.exe'
$env:BLENDER = Join-Path $tools 'blender-5.2.3/blender.exe'
$env:FFPROBE = Join-Path $tools 'ffmpeg-8.1.2/bin/ffprobe.exe'
$env:PATH = "$(Join-Path $tools 'vclibs-14.0.33321');$env:PATH"
& $projectPython -m playwright install chromium
& $projectPython -X utf8 tools/check_portable.py --out qa/portable-check
```

Проверка собирает 2D и 3D без Dota, проверяет точечную правку и возобновление рендера. Для быстрой проверки раскладки используется `tools/check.py`. Формат ручных 2D-сцен описан в [SCENES.md](../SCENES.md).

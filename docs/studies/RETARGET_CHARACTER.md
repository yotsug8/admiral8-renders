# Retarget на Пудже: ограниченный перенос верхней части тела

Проверен исходный Retarget 5.2.0 на Blender 5.2.3 LTS. Шесть костей
переносят малое движение на настоящую кожу, одежду и крюк; bake сохраняется
и открывается без аддона. Это техническая совместимость, не готовое
актёрское действие, походка или универсальный mocap.

## Воспроизведение

Код — `tools/blender/study_retarget_character.py`, общие функции —
`study_retarget_smoke.py`. Пакет, SHA256 и изоляция — [RETARGET_SMOKE](RETARGET_SMOKE.md).
В новой `_game/study/retarget_character/` нужны тот же проверенный
`retarget.zip`, его распаковка в `package/` и четыре каталога `profile/`.
Четыре переменные `BLENDER_USER_*` направить туда по инструкции smoke.
Это временный профиль процесса; Python audit hook не является системной
песочницей. Аддон не устанавливается в рабочий профиль.

Исходник — `_game/study/foundations/reach_witness/point_A.blend`,
SHA256 `287c698f6a3061355960a68120f2b66d7b383b65074497f135f10702a9ddb8b0`.
Его создание описано в [CHARACTER_OVERLAP](CHARACTER_OVERLAP.md).
Модель и текстуры относятся к внешним локальным ресурсам, не входят в main.

```powershell
foreach ($mode in @('build', 'audit', 'keys')) {
    & $env:BLENDER -b --factory-startup --disable-autoexec --python-exit-code 1 --python tools/blender/study_retarget_character.py -- --out _game/study/retarget_character --mode $mode
    if ($LASTEXITCODE -ne 0) { throw "Failed: $mode" }
}
# После просмотра шести ключевых кадров:
& $env:BLENDER -b --factory-startup --disable-autoexec --python-exit-code 1 --python tools/blender/study_retarget_character.py -- --out _game/study/retarget_character --mode video
```

`audit`, `keys`, `video` открывают сохранённую сцену в новом процессе без
импорта аддона. Video требует отсутствия `frames_front/` и `frames_side/`;
не перезаписывает готовые последовательности. Для сборки двух ракурсов:

```powershell
ffmpeg -framerate 30 -i _game/study/retarget_character/frames_front/%04d.png -framerate 30 -i _game/study/retarget_character/frames_side/%04d.png -filter_complex '[0:v][1:v]hstack=inputs=2[v]' -map '[v]' -c:v libx264 -crf 18 -pix_fmt yuv420p -movflags +faststart _game/study/retarget_character/retarget_character.mp4
```

Можно использовать FFmpeg из `imageio_ffmpeg.get_ffmpeg_exe()`. Звука нет;
частота не изменяется. Итог: 2 с, 60 кадров, 30 fps, 1280×640.

## Метод и исправленные причины ошибок

Исходная поза кадра 0 заморожена в памяти с сохранением связей одежды
и оружия; исходный файл не изменяется. Донор повторяет rest-матрицы цепи
`root → spine1 → spine2 → spine3 → neck1 → head`, с префиксом `donor_`.
Малая синусоида spine2 ±4° и neck1 ±3°, ключи каждого кадра, LINEAR.
Mapping и binding/bake исходного пакета — как в smoke, без автоподгонки.

Две ранние проверки остановились до рендера:

1. Присвоение матрицы новой кости нулевой длины теряло ориентацию.
   Длина теперь задаётся до `EditBone.matrix`; отдельная проверка rest
   ловит ошибку до binding. Предварительная исходная поза также сверяется.
2. Смещение учебного героя примерно на 100 м от начала координат
   приводило к ошибке кожи около 0,1 мм при world-space bake в float32.
   Вся изолированная копия перенесена к началу координат; допуск кожи
   остался 0,02 мм. В производственной сцене это требует отдельного
   решения, глобальное перемещение карты не выполнялось.

Статическая отрицательная проба поймана: неподвижная анимация не проходит
сравнение с donor/live. Повторное открытие проверяет 237 моментов
с шагом четверть кадра; визуальные/геометрические проверки — 60 кадров.

## Подтверждённые результаты

| Проверка | Максимум / результат |
|---|---:|
| Донор → live, положение | 0,000760 мм |
| Live → baked → reopen, положение | 0,001723 мм |
| Live → baked → reopen, угол | 0,000021° |
| Дрейф нижней полосы подошв | 0,000300 мм |
| Изменение длины ребра сетки относительно первого кадра | 1,225× |
| Новые пары пересечённых треугольников крюк/кожа вне хвата | 0 |
| SHA256 исходного blend до/после | Совпадает |

Просмотрены все 60 кадров каждого из двух ракурсов на четырёх листах,
а кадры 1/16/46 — отдельно крупно. В этом диапазоне не обнаружены
однокадровые скачки, отрыв подошв, новые заметные проходы крюка через тело
или обрезка силуэта. Мелкие дефекты в перекрытых областях этим не исключены.
Сводные измерения и SHA медиа — `RETARGET_CHARACTER_RECEIPT.json`.

Проверка BVH считает пересечения треугольников относительно исходной позы,
исключает взвешенную область кисти/пальцев хвата; не доказывает отсутствие
полного вложения поверхностей или правильность хвата. Одежда проверена
визуально и по растяжению рёбер, без симуляции ткани. Тесак уже скрыт в
исходнике и не проверялся. Ноги не анимировались. Не проверены чужая
rest-поза, разные оси, root motion, multi-slot/NLA, лицо и сильные жесты.
Следующий практический этап — осмысленное действие целиком на герое,
а не увеличение амплитуды этой технической синусоиды.
